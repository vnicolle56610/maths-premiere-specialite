Le repérage donne un langage efficace pour traiter la géométrie par le calcul. Les ressources portent sur les coordonnées, les vecteurs, les milieux, les alignements et les translations. Ces outils seront réutilisés pour les droites, la trigonométrie et le produit scalaire.

## Objectifs

- Calculer les coordonnées de points et de vecteurs.
- Démontrer un alignement ou un parallélisme.
- Utiliser les milieux et translations dans un repère.
