## Série A — Images, antécédents, calculs rapides

<p class="auto-meta">⏱ 5 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Sans calculatrice. Répondre rapidement en distinguant image, antécédent et valeur de fonction.
</div>

<ol class="auto-questions">
<li value="1">Soit <span class="arithmatex">\(f(x)=2x-3\)</span>. Calculer <span class="arithmatex">\(f(4)\)</span>.</li>
<li value="2">Soit <span class="arithmatex">\(g(x)=x^2-5\)</span>. Calculer <span class="arithmatex">\(g(-2)\)</span>.</li>
<li value="3">Si <span class="arithmatex">\(h(3)=7\)</span>, que représente <span class="arithmatex">\(3\)</span> ? que représente <span class="arithmatex">\(7\)</span> ?</li>
<li value="4">Pour <span class="arithmatex">\(f(x)=2x-1\)</span>, trouver un antécédent de <span class="arithmatex">\(9\)</span>.</li>
<li value="5">Écrire <span class="arithmatex">\(-2\leqslant x&lt;5\)</span> sous forme d'intervalle.</li>
<li value="6">Dire si <span class="arithmatex">\(2\in[-1;4]\)</span> et si <span class="arithmatex">\(5\in[-1;4]\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><p>Pour calculer <span class="arithmatex">\(f(a)\)</span>, remplacer <span class="arithmatex">\(x\)</span> par <span class="arithmatex">\(a\)</span>. Pour chercher un antécédent, résoudre une petite équation.</p>
    <p><strong>Vigilance</strong></p><p>Dans <span class="arithmatex">\(h(3)=7\)</span>, <span class="arithmatex">\(3\)</span> n'est pas l'image : c'est l'antécédent. L'image est <span class="arithmatex">\(7\)</span>.</p>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(f(4)=2\times4-3=5\)</span>, donc <span class="arithmatex">\(\boxed{f(4)=5}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(g(-2)=(-2)^2-5=4-5=-1\)</span>, donc <span class="arithmatex">\(\boxed{g(-2)=-1}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(3\)</span> est un <strong class="auto-resultat">antécédent</strong> et <span class="arithmatex">\(7\)</span> est son <strong class="auto-resultat">image</strong>.</li>
    <li value="4"><span class="arithmatex">\(2x-1=9 \Longleftrightarrow\)</span><wbr><span class="arithmatex">\( 2x=10 \Longleftrightarrow\)</span><wbr><span class="arithmatex">\( x=5\)</span>. Antécédent : <span class="arithmatex">\(\boxed{5}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(-2\leqslant x&lt;5\)</span> se traduit par <span class="arithmatex">\(\boxed{x\in[-2;5[}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(2\in[-1;4]\)</span> est <strong class="auto-resultat">vrai</strong>; <span class="arithmatex">\(5\in[-1;4]\)</span> est <strong class="auto-resultat">faux</strong>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Image : on calcule. Antécédent : on cherche la valeur de <span class="arithmatex">\(x\)</span>. Graphiquement, un antécédent est une abscisse.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Ne pas écrire « l'antécédent de <span class="arithmatex">\(f\)</span> ». On dit : un antécédent de <span class="arithmatex">\(b\)</span> par <span class="arithmatex">\(f\)</span>.</div>

## Série B — Tableau de valeurs et changement de registre

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-figure"><table class="auto-tableau"><tr><th><span class="arithmatex">\(x\)</span></th><th><span class="arithmatex">\(-2\)</span></th><th><span class="arithmatex">\(-1\)</span></th><th><span class="arithmatex">\(0\)</span></th><th><span class="arithmatex">\(1\)</span></th><th><span class="arithmatex">\(2\)</span></th></tr><tr><th><span class="arithmatex">\(f(x)\)</span></th><td><span class="arithmatex">\(3\)</span></td><td><span class="arithmatex">\(0\)</span></td><td><span class="arithmatex">\(-1\)</span></td><td><span class="arithmatex">\(0\)</span></td><td><span class="arithmatex">\(3\)</span></td></tr></table></div>

<ol class="auto-questions">
<li value="1">Lire <span class="arithmatex">\(f(-1)\)</span>.</li>
<li value="2">Donner les antécédents de <span class="arithmatex">\(0\)</span> visibles dans le tableau.</li>
<li value="3">Donner un antécédent de <span class="arithmatex">\(3\)</span>.</li>
<li value="4">Quels points peut-on placer avec les colonnes <span class="arithmatex">\(x=0\)</span> et <span class="arithmatex">\(x=2\)</span> ?</li>
<li value="5">Pour <span class="arithmatex">\(p(x)=x^2-1\)</span>, calculer <span class="arithmatex">\(p(3)\)</span>.</li>
<li value="6">QCM : un tableau de valeurs suffit-il toujours à connaître toutes les variations ?<ol class="auto-choix" type="A"><li>Oui</li><li>Non</li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><p>Dans un tableau, la première ligne contient les antécédents. La deuxième ligne contient les images.</p>
    <p><strong>Vigilance</strong></p><p>Un tableau ne donne que les valeurs affichées. Entre deux colonnes, on ne sait pas tout sans information supplémentaire.</p>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1">Dans la colonne <span class="arithmatex">\(x=-1\)</span>, on lit <span class="arithmatex">\(\boxed{f(-1)=0}\)</span>.</li>
    <li value="2">Les zéros visibles sont <span class="arithmatex">\(f(-1)=0\)</span> et <span class="arithmatex">\(f(1)=0\)</span>, donc antécédents : <span class="arithmatex">\(\boxed{-1\text{ et }1}\)</span>.</li>
    <li value="3">On lit <span class="arithmatex">\(f(-2)=3\)</span> et <span class="arithmatex">\(f(2)=3\)</span>. Un antécédent de <span class="arithmatex">\(3\)</span> est donc <span class="arithmatex">\(\boxed{-2}\)</span> ou <span class="arithmatex">\(\boxed{2}\)</span>.</li>
    <li value="4">Les points sont <span class="arithmatex">\(\boxed{(0;-1)}\)</span> et <span class="arithmatex">\(\boxed{(2;3)}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(p(3)=3^2-1=9-1\)</span>, donc <span class="arithmatex">\(\boxed{p(3)=8}\)</span>.</li>
    <li value="6"><strong class="auto-resultat">Réponse B</strong> : Un tableau de valeurs ne suffit pas toujours.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Un point de la courbe a pour coordonnées <span class="arithmatex">\((x;f(x))\)</span>. Chaque colonne du tableau peut donner un point.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Ne pas relier automatiquement des points si on ne sait pas comment la fonction se comporte entre eux.</div>

## Série C — Lecture graphique : images, zéros, signe

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** <em> On lit les informations directement sur la courbe de <span class="arithmatex">\(f\)</span>.</em>
</div>

<div class="auto-figure"><img src="../figures/N03-fonctions-lectures-variations-bc79c0a08f.svg" alt="Figure de la série C" width="338"></div>

<ol class="auto-questions">
<li value="1">Lire <span class="arithmatex">\(f(-3)\)</span>.</li>
<li value="2">Donner les zéros de <span class="arithmatex">\(f\)</span>.</li>
<li value="3">Donner un antécédent de <span class="arithmatex">\(-2\)</span>.</li>
<li value="4">Sur quels intervalles lit-on <span class="arithmatex">\(f(x)&gt;0\)</span> ?</li>
<li value="5">Vrai ou faux : <span class="arithmatex">\(f(2)&lt;0\)</span>.</li>
<li value="6">QCM : si la courbe est au-dessus de l'axe des abscisses, alors<ol class="auto-choix" type="A"><li><span class="arithmatex">\(f(x)&gt;0\)</span></li><li><span class="arithmatex">\(f(x)&lt;0\)</span></li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><p>Zéros : intersections avec l'axe des abscisses. Signe : position de la courbe par rapport à cet axe.</p>
    <p><strong>Vigilance</strong></p><p>Lire <span class="arithmatex">\(f(x)&gt;0\)</span> ne veut pas dire « <span class="arithmatex">\(x\)</span> est positif ». C'est l'image <span class="arithmatex">\(f(x)\)</span> qui est positive.</p>

??? success "Corrigé de la série C"

    <div class="auto-figure"><img src="../figures/N03-fonctions-lectures-variations-e787a0b33f.svg" alt="Figure de la série C" width="356"></div>
    <ol class="auto-corrige">
    <li value="1">On lit <span class="arithmatex">\(\boxed{f(-3)=-1}\)</span>.</li>
    <li value="2">Les zéros sont <span class="arithmatex">\(\boxed{-2,\ 1,\ 3}\)</span>.</li>
    <li value="3">On lit <span class="arithmatex">\(\boxed{2}\)</span>, car <span class="arithmatex">\(f(2)=-2\)</span>.</li>
    <li value="4"><span class="arithmatex">\(\boxed{f(x)&gt;0}\)</span> sur <span class="arithmatex">\(]-2;1[\)</span> et <span class="arithmatex">\(]3;4]\)</span>.</li>
    <li value="5">Vrai : <span class="arithmatex">\(f(2)=-2\)</span>, donc <span class="arithmatex">\(\boxed{\text{vrai}}\)</span>.</li>
    <li value="6"><strong class="auto-resultat">Réponse A</strong> : Au-dessus de l'axe : <span class="arithmatex">\(f(x)&gt;0\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Pour le signe, on découpe l'axe des abscisses avec les zéros.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Dans un tableau de signes, la ligne porte sur <span class="arithmatex">\(f(x)\)</span>, pas sur <span class="arithmatex">\(f\)</span>.</div>

## Série D — Variations et choix du registre

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** <em> On utilise le tableau de variations ci-dessous. Répondre rapidement.</em>
</div>

<div class="auto-figure"><img src="../figures/N03-fonctions-lectures-variations-01b02c5284.svg" alt="Figure de la série D" width="374"></div>

<ol class="auto-questions">
<li value="1">Sur quel intervalle <span class="arithmatex">\(f\)</span> est-elle décroissante ?</li>
<li value="2">Lire un maximum local visible dans le tableau.</li>
<li value="3">Comparer <span class="arithmatex">\(f(-3)\)</span> et <span class="arithmatex">\(f(-1)\)</span>.</li>
<li value="4">Pour calculer <span class="arithmatex">\(f(5)\)</span> exactement, quel registre choisir ?</li>
<li value="5">Tableau de variations : écrit-on <span class="arithmatex">\(f\)</span> ou <span class="arithmatex">\(f(x)\)</span> ?</li>
<li value="6">QCM : pour savoir où <span class="arithmatex">\(f(x)&gt;0\)</span>, le plus adapté est<ol class="auto-choix" type="A"><li>tableau de signes</li><li>tableau de variations</li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><p>Une flèche montante indique que la fonction augmente. Une flèche descendante indique qu'elle diminue.</p>
    <p><strong>Vigilance</strong></p><p>Un tableau de variations ne donne pas le signe. Il indique le sens de variation et certaines valeurs.</p>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1">La fonction <span class="arithmatex">\(f\)</span> est décroissante sur <span class="arithmatex">\(\boxed{[-1;2]}\)</span>.</li>
    <li value="2">On lit un maximum local égal à <span class="arithmatex">\(\boxed{3}\)</span>, atteint pour <span class="arithmatex">\(x=-1\)</span>.</li>
    <li value="3"><span class="arithmatex">\(f(-3)=-1\)</span> et <span class="arithmatex">\(f(-1)=3\)</span>, donc <span class="arithmatex">\(\boxed{f(-3)&lt;f(-1)}\)</span>.</li>
    <li value="4">Pour calculer exactement, on choisit <strong class="auto-resultat">l'expression de la fonction</strong>.</li>
    <li value="5">Dans un tableau de variations, on écrit <span class="arithmatex">\(\boxed{f}\)</span>, pas <span class="arithmatex">\(f(x)\)</span>.</li>
    <li value="6"><strong class="auto-resultat">Réponse A</strong> : tableau de signes</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Variations : on étudie la fonction <span class="arithmatex">\(f\)</span>. Signe : on étudie les valeurs <span class="arithmatex">\(f(x)\)</span>.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Ne pas confondre « <span class="arithmatex">\(f\)</span> augmente » avec « <span class="arithmatex">\(f(x)\)</span> est positif ».</div>
