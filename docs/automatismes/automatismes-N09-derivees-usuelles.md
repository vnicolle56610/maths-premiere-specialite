## Série A — Réactiver tangentes et algèbre

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Répondre vite. Les calculs doivent rester exacts.
</div>

<ol class="auto-questions">
<li value="1">Développer <span class="arithmatex">\((x-3)^2\)</span>.</li>
<li value="2">Factoriser <span class="arithmatex">\(x^2-6x+9\)</span>.</li>
<li value="3">Résoudre <span class="arithmatex">\(2x+8=0\)</span>.</li>
<li value="4">Si <span class="arithmatex">\(f(2)=5\)</span> et <span class="arithmatex">\(f'(2)=3\)</span>, donner la tangente en <span class="arithmatex">\(2\)</span>.</li>
<li value="5">Pour <span class="arithmatex">\(f(x)=x^2\)</span>, calculer <span class="arithmatex">\(f'(4)\)</span>.</li>
<li value="6">Quel est le signe de <span class="arithmatex">\(3x-6\)</span> lorsque <span class="arithmatex">\(x&gt;2\)</span> ?</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Reconnaître les formes avant de développer.</li><li>Une tangente utilise <span class="arithmatex">\(f(a)\)</span> et <span class="arithmatex">\(f'(a)\)</span>.</li><li>Le signe d'une expression affine change à sa racine.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Ne pas oublier le double produit.</li><li>Le nombre dérivé est un coefficient directeur.</li></ul>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\((x-3)^2=\boxed{x^2-6x+9}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(x^2-6x+9=\)</span><wbr><span class="arithmatex">\((x-3)^2=\)</span><wbr><span class="arithmatex">\(\boxed{(x-3)^2}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(2x+8=0 \iff\)</span><wbr><span class="arithmatex">\( 2x=-8 \iff\)</span><wbr><span class="arithmatex">\( \boxed{x=-4}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(y=5+3(x-2)\)</span>, donc <span class="arithmatex">\(\boxed{y=3x-1}\)</span>.</li>
    <li value="5">Pour <span class="arithmatex">\(x^2\)</span>, <span class="arithmatex">\(f'(x)=2x\)</span>. Donc <span class="arithmatex">\(f'(4)=\boxed{8}\)</span>.</li>
    <li value="6">Si <span class="arithmatex">\(x&gt;2\)</span>, alors <span class="arithmatex">\(3x-6&gt;0\)</span>. Signe : <span class="arithmatex">\(\boxed{+}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Une dérivée usuelle doit être reconnue rapidement, mais les transformations algébriques restent justifiées.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Le signe <span class="arithmatex">\(+\)</span> ou <span class="arithmatex">\(-\)</span> porte sur un nombre réel, pas sur une expression isolée du contexte.</div>

## Série B — Dérivées usuelles

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Donner la dérivée de chaque fonction sur son intervalle de définition.
</div>

<ol class="auto-questions">
<li value="1"><span class="arithmatex">\(f(x)=7\)</span>.</li>
<li value="2"><span class="arithmatex">\(f(x)=x\)</span>.</li>
<li value="3"><span class="arithmatex">\(f(x)=x^2\)</span>.</li>
<li value="4"><span class="arithmatex">\(f(x)=x^3\)</span>.</li>
<li value="5"><span class="arithmatex">\(f(x)=\dfrac1x\)</span>, pour <span class="arithmatex">\(x\neq0\)</span>.</li>
<li value="6"><span class="arithmatex">\(f(x)=\sqrt{x}\)</span>, pour <span class="arithmatex">\(x&gt;0\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Une constante a une dérivée nulle.</li><li>Pour <span class="arithmatex">\(x^n\)</span>, multiplier par <span class="arithmatex">\(n\)</span> puis diminuer l'exposant de <span class="arithmatex">\(1\)</span>.</li><li>Vérifier l'intervalle de définition.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li><span class="arithmatex">\(\dfrac1x\)</span> n'est pas dérivée comme <span class="arithmatex">\(x\)</span>.</li><li><span class="arithmatex">\(\sqrt{x}\)</span> nécessite <span class="arithmatex">\(x&gt;0\)</span> pour sa dérivée.</li></ul>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\boxed{f'(x)=0}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(\boxed{f'(x)=1}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\boxed{f'(x)=2x}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(\boxed{f'(x)=3x^2}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(\boxed{f'(x)=-\dfrac1{x^2}}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(\boxed{f'(x)=\dfrac1{2\sqrt{x}}}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Les dérivées usuelles sont des automatismes : elles servent ensuite aux sommes, produits et quotients.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Indiquer l'intervalle évite d'utiliser une formule hors de son domaine.</div>

## Série C — Sommes, produits et quotients

<p class="auto-meta">⏱ 8 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Calculer la dérivée. Ne pas développer inutilement.
</div>

<ol class="auto-questions">
<li value="1"><span class="arithmatex">\(f(x)=3x^2-5x+1\)</span>.</li>
<li value="2"><span class="arithmatex">\(g(x)=x^3-4x^2+6\)</span>.</li>
<li value="3"><span class="arithmatex">\(h(x)=x^2+\dfrac1x\)</span>, pour <span class="arithmatex">\(x\neq0\)</span>.</li>
<li value="4"><span class="arithmatex">\(p(x)=(x^2+1)(x-3)\)</span>.</li>
<li value="5"><span class="arithmatex">\(q(x)=\dfrac{2x+1}{x-1}\)</span>, pour <span class="arithmatex">\(x\neq1\)</span>.</li>
<li value="6"><span class="arithmatex">\(r(x)=x^2(x-4)\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Dériver terme à terme une somme.</li><li>Produit : <span class="arithmatex">\(u'v+uv'\)</span>.</li><li>Quotient : <span class="arithmatex">\(\dfrac{u'v-uv'}{v^2}\)</span>.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Ne pas dériver un produit terme à terme.</li><li>Le dénominateur du quotient est <span class="arithmatex">\(v^2\)</span>.</li></ul>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\boxed{f'(x)=6x-5}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(\boxed{g'(x)=3x^2-8x}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\boxed{h'(x)=2x-\dfrac1{x^2}}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(p'(x)=\)</span><wbr><span class="arithmatex">\(2x(x-3)+(x^2+1)\times1\)</span>. Donc <span class="arithmatex">\(\boxed{p'(x)=2x(x-3)+x^2+1}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(q'(x)=\)</span><wbr><span class="arithmatex">\(\dfrac{2(x-1)-(2x+1)}{(x-1)^2}=\)</span><wbr><span class="arithmatex">\(\boxed{-\dfrac3{(x-1)^2}}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(r'(x)=\)</span><wbr><span class="arithmatex">\(2x(x-4)+x^2=\)</span><wbr><span class="arithmatex">\(\boxed{3x^2-8x}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Identifier <span class="arithmatex">\(u\)</span> et <span class="arithmatex">\(v\)</span> avant d'appliquer une formule. La multiplication numérique explicite s'écrit <span class="arithmatex">\(\times\)</span> si elle évite une ambiguïté.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Un quotient est défini seulement lorsque son dénominateur est non nul.</div>

## Série D — Type épreuve anticipée : QCM

<p class="auto-meta">⏱ 5 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Choisir une seule réponse. Aucune justification n'est demandée.
</div>

<ol class="auto-questions">
<li value="1">La dérivée de <span class="arithmatex">\(x^4\)</span> est :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(x^3\)</span></li><li><span class="arithmatex">\(4x^3\)</span></li><li><span class="arithmatex">\(4x^4\)</span></li><li><span class="arithmatex">\(x^5\)</span></li></ol></li>
<li value="2">La dérivée de <span class="arithmatex">\(5x^2-3x+1\)</span> est :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(10x-3\)</span></li><li><span class="arithmatex">\(5x-3\)</span></li><li><span class="arithmatex">\(10x+1\)</span></li><li><span class="arithmatex">\(5x^2-3\)</span></li></ol></li>
<li value="3">La dérivée de <span class="arithmatex">\(\dfrac1x\)</span> est :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(\dfrac1{x^2}\)</span></li><li><span class="arithmatex">\(-\dfrac1{x^2}\)</span></li><li><span class="arithmatex">\(-\dfrac1x\)</span></li><li><span class="arithmatex">\(x^2\)</span></li></ol></li>
<li value="4"><span class="arithmatex">\(f(x)=x^2+4x\)</span>. Alors <span class="arithmatex">\(f'(2)=\)</span><ol class="auto-choix" type="A"><li><span class="arithmatex">\(4\)</span></li><li><span class="arithmatex">\(6\)</span></li><li><span class="arithmatex">\(8\)</span></li><li><span class="arithmatex">\(12\)</span></li></ol></li>
<li value="5">La dérivée de <span class="arithmatex">\((x^2+1)(x-2)\)</span> est :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(2x(x-2)+x^2+1\)</span></li><li><span class="arithmatex">\(2x+x-2\)</span></li><li><span class="arithmatex">\((2x)(1)\)</span></li><li><span class="arithmatex">\(x^2+1\)</span></li></ol></li>
<li value="6">La dérivée d'une constante est :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(1\)</span></li><li><span class="arithmatex">\(x\)</span></li><li><span class="arithmatex">\(0\)</span></li><li><span class="arithmatex">\(la constante\)</span></li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Reconnaître la formule avant de calculer.</li><li>Dans un QCM, tester une valeur peut aider.</li><li>Attention aux signes.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Le piège classique : oublier le signe moins de <span class="arithmatex">\(\dfrac1x\)</span>.</li><li>Un produit n'a pas pour dérivée le produit des dérivées.</li></ul>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\((x^4)'=4x^3\)</span>.</li>
    <li value="2"><strong class="auto-resultat">Réponse A</strong> : <span class="arithmatex">\(5x^2\)</span> donne <span class="arithmatex">\(10x\)</span>, <span class="arithmatex">\(-3x\)</span> donne <span class="arithmatex">\(-3\)</span>.</li>
    <li value="3"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\(\left(\dfrac1x\right)'=\)</span><wbr><span class="arithmatex">\(-\dfrac1{x^2}\)</span>.</li>
    <li value="4"><strong class="auto-resultat">Réponse C</strong> : <span class="arithmatex">\(f'(x)=2x+4\)</span>, donc <span class="arithmatex">\(f'(2)=8\)</span>.</li>
    <li value="5"><strong class="auto-resultat">Réponse A</strong> : On applique <span class="arithmatex">\((uv)'=u'v+uv'\)</span>.</li>
    <li value="6"><strong class="auto-resultat">Réponse C</strong> : Une constante ne varie pas.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Pour gagner du temps, mémoriser les dérivées usuelles et vérifier la structure : somme, produit ou quotient.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> La rapidité ne doit pas effacer les conditions de définition.</div>
