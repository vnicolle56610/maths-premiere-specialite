## Série A — Réactivation N01, N02 et N05 ; calcul littéral

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Calculer ou répondre sans calculatrice.
</div>

<ol class="auto-questions">
<li value="1"><span class="arithmatex">\(\dfrac34-\dfrac5{12}\)</span></li>
<li value="2">Développer <span class="arithmatex">\((x-4)^2\)</span>.</li>
<li value="3">Sommet de <span class="arithmatex">\(x\mapsto-2(x+1)^2+5\)</span>.</li>
<li value="4">Résoudre <span class="arithmatex">\(5x-7=3\)</span>.</li>
<li value="5">Traduire <span class="arithmatex">\(x\in]-3;2]\)</span> par une double inégalité.</li>
<li value="6">Vrai ou faux : <span class="arithmatex">\(x^2=16\Rightarrow x=4\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Mettre les fractions au même dénominateur.</li><li>Utiliser <span class="arithmatex">\((a-b)^2=a^2-2ab+b^2\)</span>.</li><li>Lire <span class="arithmatex">\(a,\alpha,\beta\)</span> sans développer.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li><span class="arithmatex">\(x^2=16\)</span> possède deux solutions.</li><li>Dans <span class="arithmatex">\(x+1=x-(-1)\)</span>, on lit <span class="arithmatex">\(\alpha=-1\)</span>.</li></ul>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\dfrac9{12}-\dfrac5{12}=\)</span><wbr><span class="arithmatex">\(\boxed{\frac13}\)</span>.</li>
    <li value="2"><span class="arithmatex">\((x-4)^2=\)</span><wbr><span class="arithmatex">\(\boxed{x^2-8x+16}\)</span>.</li>
    <li value="3">Le sommet est <span class="arithmatex">\(\boxed{S(-1;5)}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(5x-7=3\Longleftrightarrow\)</span><wbr><span class="arithmatex">\(5x=10\Longleftrightarrow\)</span><wbr><span class="arithmatex">\(\boxed{x=2}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(\boxed{-3&lt;x\leq2}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(x=-4\)</span> est un contre-exemple : <strong class="auto-resultat">faux</strong>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Reconnaître le type de question avant de calculer : fraction, identité, forme canonique, équation ou logique.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Une implication est fausse dès qu'un contre-exemple existe.</div>

## Série B — Formes, racines et méthodes courtes

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Donner le résultat et indiquer mentalement la méthode utilisée.
</div>

<ol class="auto-questions">
<li value="1">Racines de <span class="arithmatex">\(3(x-2)(x+5)\)</span>.</li>
<li value="2">Résoudre <span class="arithmatex">\(x^2-6x=0\)</span>.</li>
<li value="3">Résoudre <span class="arithmatex">\(x^2-25=0\)</span>.</li>
<li value="4">Résoudre <span class="arithmatex">\((x-3)^2-7=0\)</span>.</li>
<li value="5">Factoriser <span class="arithmatex">\(x^2-16x+55\)</span>.</li>
<li value="6">Tester si <span class="arithmatex">\(1\)</span> est racine de <span class="arithmatex">\(3x^2+7x-10\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Chercher d'abord une forme factorisée.</li><li>Pour <span class="arithmatex">\(x^2-sx+p\)</span>, chercher deux nombres de somme <span class="arithmatex">\(s\)</span> et de produit <span class="arithmatex">\(p\)</span>.</li><li>Tester une racine en calculant son image.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Une racine annule le trinôme.</li><li>Ne pas utiliser <span class="arithmatex">\(\Delta\)</span> quand une méthode immédiate suffit.</li></ul>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\boxed{x=2}\)</span> ou <span class="arithmatex">\(\boxed{x=-5}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(x(x-6)=0\)</span>, donc <span class="arithmatex">\(\boxed{\mathcal S=\{0;6\}}\)</span>.</li>
    <li value="3"><span class="arithmatex">\((x-5)(x+5)=0\)</span>, donc <span class="arithmatex">\(\boxed{\mathcal S=\{-5;5\}}\)</span>.</li>
    <li value="4"><span class="arithmatex">\((x-3)^2=7\)</span>, donc <span class="arithmatex">\(\boxed{x=3\pm\sqrt7}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(5+11=16\)</span>, <span class="arithmatex">\(5\times11=55\)</span> : <span class="arithmatex">\(\boxed{x^2-16x+55=(x-5)(x-11)}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(P(1)=3+7-10=0\)</span> : <strong class="auto-resultat"><span class="arithmatex">\(1\)</span> est une racine</strong>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Ordre conseillé : facteur commun, identité remarquable, forme canonique, racine évidente, puis discriminant.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Pour <span class="arithmatex">\(3x^2+7x-10=(x-1)(3x+10)\)</span>, l'autre racine est <span class="arithmatex">\(-10/3\)</span>.</div>

## Série C — Discriminant, factorisation et signe

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Calculer rapidement ou conclure à partir du discriminant.
</div>

<ol class="auto-questions">
<li value="1">Pour <span class="arithmatex">\(2x^2-5x-3\)</span>, donner <span class="arithmatex">\(a,b,c\)</span>.</li>
<li value="2">Calculer <span class="arithmatex">\(\Delta\)</span> pour <span class="arithmatex">\(x^2-6x+5\)</span>.</li>
<li value="3">Nombre de racines de <span class="arithmatex">\(3x^2+2x+4\)</span>.</li>
<li value="4">Résoudre <span class="arithmatex">\(x^2-7x+10=0\)</span>.</li>
<li value="5">Factoriser <span class="arithmatex">\(4x^2-12x+9\)</span>.</li>
<li value="6">Signe de <span class="arithmatex">\(2(x+1)(x-3)\)</span> sur <span class="arithmatex">\(]-1;3[\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Prendre <span class="arithmatex">\(b\)</span> avec son signe.</li><li><span class="arithmatex">\(\Delta=b^2-4ac\)</span>.</li><li>Entre deux racines, le signe est opposé à celui de <span class="arithmatex">\(a\)</span>.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li><span class="arithmatex">\((-5)^2=25\)</span>.</li><li>Une racine double ne change pas le signe du trinôme.</li></ul>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\boxed{a=2},\ \boxed{b=-5},\ \boxed{c=-3}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(\Delta=\)</span><wbr><span class="arithmatex">\((-6)^2-4\times1\times5=\)</span><wbr><span class="arithmatex">\(\boxed{16}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\Delta=\)</span><wbr><span class="arithmatex">\(2^2-4\times3\times4=\)</span><wbr><span class="arithmatex">\(-44&lt;0\)</span> : <strong class="auto-resultat">aucune racine réelle</strong>.</li>
    <li value="4"><span class="arithmatex">\(\Delta=9\)</span>, donc <span class="arithmatex">\(\boxed{\mathcal S=\{2;5\}}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(\Delta=0\)</span>, racine double <span class="arithmatex">\(3/2\)</span> : <span class="arithmatex">\(\boxed{4x^2-12x+9=(2x-3)^2}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(a=2&gt;0\)</span> : entre les racines, le signe est <span class="arithmatex">\(\boxed{-}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Après le calcul de <span class="arithmatex">\(\Delta\)</span>, annoncer le cas avant de calculer les racines ou de factoriser.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Le tableau de signes dépend du signe de <span class="arithmatex">\(a\)</span>, pas seulement des racines.</div>

## Série D — QCM cumulatif N01, N02, N05 et N06

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Choisir une seule réponse. Aucune justification n'est demandée.
</div>

<ol class="auto-questions">
<li value="1">Racines de <span class="arithmatex">\((x+2)(x-5)\)</span> :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(-2,5\)</span></li><li><span class="arithmatex">\(2,-5\)</span></li><li><span class="arithmatex">\(2,5\)</span></li></ol></li>
<li value="2">Pour <span class="arithmatex">\(x^2-9x+20\)</span>, somme et produit :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(9,20\)</span></li><li><span class="arithmatex">\(-9,20\)</span></li><li><span class="arithmatex">\(9,-20\)</span></li></ol></li>
<li value="3">Si <span class="arithmatex">\(\Delta&lt;0\)</span> et <span class="arithmatex">\(a&gt;0\)</span>, le trinôme est :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(&gt;0\)</span></li><li><span class="arithmatex">\(&lt;0\)</span></li><li>de signe variable</li></ol></li>
<li value="4"><span class="arithmatex">\(\Delta\)</span> de <span class="arithmatex">\(2x^2+x-3\)</span> :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(25\)</span></li><li><span class="arithmatex">\(-23\)</span></li><li><span class="arithmatex">\(7\)</span></li></ol></li>
<li value="5">Sommet de <span class="arithmatex">\(x\mapsto-3(x-2)^2+4\)</span> :<ol class="auto-choix" type="A"><li><span class="arithmatex">\((2;4)\)</span></li><li><span class="arithmatex">\((-2;4)\)</span></li><li><span class="arithmatex">\((2;-4)\)</span></li></ol></li>
<li value="6"><span class="arithmatex">\(x^2=4\Rightarrow x=2\)</span> :<ol class="auto-choix" type="A"><li>vraie</li><li>fausse</li><li>équivalence</li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Lire les facteurs avant de développer.</li><li>Dans <span class="arithmatex">\(x^2-sx+p\)</span>, la somme vaut <span class="arithmatex">\(s\)</span>.</li><li>En QCM, éliminer les réponses incompatibles.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Une seule réponse est correcte.</li><li>Ne pas oublier la solution négative d'une équation <span class="arithmatex">\(x^2=k\)</span>.</li></ul>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">Réponse A</strong> : Racines <span class="arithmatex">\(-2\)</span> et <span class="arithmatex">\(5\)</span>.</li>
    <li value="2"><strong class="auto-resultat">Réponse A</strong> : <span class="arithmatex">\(s=9\)</span>, <span class="arithmatex">\(p=20\)</span>.</li>
    <li value="3"><strong class="auto-resultat">Réponse A</strong> : Sans racine et <span class="arithmatex">\(a&gt;0\)</span>, le trinôme est strictement positif.</li>
    <li value="4"><strong class="auto-resultat">Réponse A</strong> : <span class="arithmatex">\(\Delta=\)</span><wbr><span class="arithmatex">\(1^2-4\times2\times(-3)=\)</span><wbr><span class="arithmatex">\(25\)</span>.</li>
    <li value="5"><strong class="auto-resultat">Réponse A</strong> : <span class="arithmatex">\(S(2;4)\)</span>.</li>
    <li value="6"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\(x=-2\)</span> est un contre-exemple.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Lire la structure avant de calculer. Contrôler la cohérence graphique du nombre de racines et du signe.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Une formule correcte ne dispense pas d'un contrôle de signe et d'une conclusion.</div>
