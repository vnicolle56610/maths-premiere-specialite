## Série A — 

<div class="auto-consigne" markdown>
**Consigne.** Remobiliser des automatismes de calcul sans indication de chapitre.
</div>

<ol class="auto-questions">
<li value="1">Résoudre <span class="arithmatex">\(2x-5=7\)</span>.</li>
<li value="2">Développer <span class="arithmatex">\((x-3)^2\)</span>.</li>
<li value="3">Factoriser <span class="arithmatex">\(x^2-9\)</span>.</li>
<li value="4">Calculer la dérivée de <span class="arithmatex">\(f(x)=3x^2-4x+1\)</span>.</li>
<li value="5">Simplifier <span class="arithmatex">\(\mathrm e^2\times \mathrm e^5\)</span>.</li>
<li value="6">Si <span class="arithmatex">\(P(A)=0{,}3\)</span>, calculer <span class="arithmatex">\(P(\overline A)\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Identifier la famille de calcul avant de démarrer.</li><li>Écrire peu, mais juste.</li><li>Changer d'outil dès que la forme le demande.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Ne pas appliquer une formule hors contexte.</li><li>Conserver les notations exactes.</li></ul>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(2x=12\)</span>, donc <span class="arithmatex">\(\mathscr S=\boxed{\{6\}}\)</span>.</li>
    <li value="2"><span class="arithmatex">\((x-3)^2=\boxed{x^2-6x+9}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(x^2-9=\boxed{(x-3)(x+3)}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(f'(x)=\boxed{6x-4}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(\mathrm e^2\times \mathrm e^5=\)</span><wbr><span class="arithmatex">\(\boxed{\mathrm e^7}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(P(\overline A)=\)</span><wbr><span class="arithmatex">\(1-0{,}3=\)</span><wbr><span class="arithmatex">\(\boxed{0{,}7}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Passer d'un registre à l'autre sans attendre l'intitulé du chapitre. Vérifier la nature de l'objet obtenu : nombre, fonction ou événement.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Une bonne automatisation garde le sens de la notation.</div>

## Série B — 

<div class="auto-consigne" markdown>
**Consigne.** Choisir une méthode adaptée à la forme donnée.
</div>

<ol class="auto-questions">
<li value="1">Pour résoudre <span class="arithmatex">\(x^2-5x=0\)</span>, quelle forme utiliser en priorité ?</li>
<li value="2">Pour étudier le signe de <span class="arithmatex">\(2(x-1)(x+4)\)</span>, quelle information lit-on directement ?</li>
<li value="3">Pour <span class="arithmatex">\(f(x)=x^3-3x\)</span>, quel outil permet d'étudier les variations ?</li>
<li value="4">Pour une suite <span class="arithmatex">\(u_n=5+3n\)</span>, reconnaître le type de suite.</li>
<li value="5">Pour deux événements indépendants <span class="arithmatex">\(A\)</span> et <span class="arithmatex">\(B\)</span>, quelle formule calcule <span class="arithmatex">\(P(A\cap B)\)</span> ?</li>
<li value="6">Pour une variable aléatoire <span class="arithmatex">\(X\)</span>, quelle grandeur donne la moyenne attendue ?</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Regarder la forme avant d'effectuer un calcul.</li><li>Associer outil et objectif : résoudre, dériver, comparer, prévoir.</li><li>Une réponse courte peut suffire si elle est précise.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Ne pas développer si la forme factorisée donne déjà l'information.</li><li>Ne pas confondre formule et interprétation.</li></ul>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1">On factorise : <span class="arithmatex">\(x(x-5)=0\)</span>. Forme prioritaire : <span class="arithmatex">\(\boxed{forme factorisée}\)</span>.</li>
    <li value="2">Les racines <span class="arithmatex">\(1\)</span> et <span class="arithmatex">\(-4\)</span>, puis le signe du coefficient <span class="arithmatex">\(2&gt;0\)</span>.</li>
    <li value="3">On calcule <span class="arithmatex">\(f'\)</span>, puis on utilise le signe de <span class="arithmatex">\(f'\)</span> : <span class="arithmatex">\(\boxed{dérivation}\)</span>.</li>
    <li value="4">C'est une <span class="arithmatex">\(\boxed{suite arithmétique}\)</span> de raison <span class="arithmatex">\(3\)</span>.</li>
    <li value="5"><span class="arithmatex">\(P(A\cap B)=\)</span><wbr><span class="arithmatex">\(\boxed{P(A)P(B)}\)</span>.</li>
    <li value="6">La moyenne attendue est <strong class="auto-resultat">l'espérance <span class="arithmatex">\(E(X)\)</span></strong>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Le choix de méthode est souvent plus important que le calcul. Identifier la forme utile : factorisée, dérivée, loi, arbre.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Un automatisme n'est pas une recette unique : c'est un choix rapide.</div>

## Série C — 

<div class="auto-consigne" markdown>
**Consigne.** Enchaîner de courts raisonnements cumulatifs.
</div>

<ol class="auto-questions">
<li value="1">Soit <span class="arithmatex">\(f(x)=x^2-4x+1\)</span>. Calculer <span class="arithmatex">\(f'(x)\)</span>.</li>
<li value="2">Déterminer le signe de <span class="arithmatex">\(f'(x)\)</span>.</li>
<li value="3">En déduire le sens de variation de <span class="arithmatex">\(f\)</span>.</li>
<li value="4">Calculer <span class="arithmatex">\(f(2)\)</span>.</li>
<li value="5">Si <span class="arithmatex">\(X\)</span> prend les valeurs <span class="arithmatex">\(0\)</span> et <span class="arithmatex">\(4\)</span> avec probabilités <span class="arithmatex">\(0{,}25\)</span> et <span class="arithmatex">\(0{,}75\)</span>, calculer <span class="arithmatex">\(E(X)\)</span>.</li>
<li value="6">Si <span class="arithmatex">\(A\)</span> et <span class="arithmatex">\(B\)</span> sont indépendants, <span class="arithmatex">\(P(A)=0{,}5\)</span>, <span class="arithmatex">\(P(B)=0{,}2\)</span>, calculer <span class="arithmatex">\(P(A\cap B)\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Un mini-enchaînement doit rester ordonné.</li><li>Le signe d'une dérivée pilote les variations.</li><li>Traiter chaque registre avec sa formule propre.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Une dérivée est une fonction.</li><li>Ne pas mélanger espérance et probabilité.</li></ul>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(f'(x)=\boxed{2x-4}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(2x-4&lt;0\)</span> si <span class="arithmatex">\(x&lt;2\)</span>, <span class="arithmatex">\(=0\)</span> si <span class="arithmatex">\(x=2\)</span>, <span class="arithmatex">\(&gt;0\)</span> si <span class="arithmatex">\(x&gt;2\)</span>.</li>
    <li value="3"><span class="arithmatex">\(f\)</span> est <strong class="auto-resultat">décroissante sur <span class="arithmatex">\((-\infty,2]\)</span>, puis croissante sur <span class="arithmatex">\([2,+\infty)\)</span></strong>.</li>
    <li value="4"><span class="arithmatex">\(f(2)=4-8+1=\boxed{-3}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(E(X)=\)</span><wbr><span class="arithmatex">\(0\times0{,}25+4\times0{,}75=\)</span><wbr><span class="arithmatex">\(\boxed{3}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(P(A\cap B)=\)</span><wbr><span class="arithmatex">\(0{,}5\times0{,}2=\)</span><wbr><span class="arithmatex">\(\boxed{0{,}1}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Calculer, interpréter, conclure. Relier signe de la dérivée et variations.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Une conclusion de variation doit mentionner les intervalles.</div>

## Série D — 

<div class="auto-consigne" markdown>
**Consigne.** QCM cumulatif type automatismes. Une seule réponse correcte.
</div>

<ol class="auto-questions">
<li value="1"><span class="arithmatex">\((2x)^2=\)</span><ol class="auto-choix" type="A"><li><span class="arithmatex">\(2x^2\)</span></li><li><span class="arithmatex">\(4x^2\)</span></li><li><span class="arithmatex">\(4x\)</span></li><li><span class="arithmatex">\(x^2+4\)</span></li></ol></li>
<li value="2">La dérivée de <span class="arithmatex">\(\mathrm e^x+5x\)</span> est<ol class="auto-choix" type="A"><li><span class="arithmatex">\(\mathrm e^x+5\)</span></li><li><span class="arithmatex">\(\mathrm e^x\)</span></li><li><span class="arithmatex">\(x\mathrm e^{x-1}\)</span></li><li><span class="arithmatex">\(5\mathrm e^x\)</span></li></ol></li>
<li value="3">Si <span class="arithmatex">\(P(A)=0{,}25\)</span>, alors <span class="arithmatex">\(P(\overline A)=\)</span><ol class="auto-choix" type="A"><li><span class="arithmatex">\(0{,}25\)</span></li><li><span class="arithmatex">\(0{,}5\)</span></li><li><span class="arithmatex">\(0{,}75\)</span></li><li><span class="arithmatex">\(1{,}25\)</span></li></ol></li>
<li value="4">Une suite arithmétique de raison <span class="arithmatex">\(-2\)</span> est<ol class="auto-choix" type="A"><li>croissante</li><li>décroissante</li><li>géométrique</li><li>constante</li></ol></li>
<li value="5"><span class="arithmatex">\(\mathrm e^{3}/\mathrm e=\)</span><ol class="auto-choix" type="A"><li><span class="arithmatex">\(\mathrm e^3\)</span></li><li><span class="arithmatex">\(\mathrm e^4\)</span></li><li><span class="arithmatex">\(\mathrm e^2\)</span></li><li><span class="arithmatex">\(3\)</span></li></ol></li>
<li value="6">Si <span class="arithmatex">\(E(G)=-1{,}5\)</span>, le jeu est<ol class="auto-choix" type="A"><li>favorable au joueur</li><li>équilibré</li><li>défavorable au joueur</li><li>impossible</li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Le QCM final mélange les thèmes.</li><li>Repérer la formule cachée avant de choisir.</li><li>Vérifier les ordres de grandeur.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Les puissances s'appliquent aussi aux coefficients.</li><li>Un signe négatif d'espérance a un sens.</li></ul>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\(4x^2\)</span></li>
    <li value="2"><strong class="auto-resultat">Réponse A</strong> : <span class="arithmatex">\(\mathrm e^x+5\)</span></li>
    <li value="3"><strong class="auto-resultat">Réponse C</strong> : <span class="arithmatex">\(0{,}75\)</span></li>
    <li value="4"><strong class="auto-resultat">Réponse B</strong> : décroissante</li>
    <li value="5"><strong class="auto-resultat">Réponse C</strong> : <span class="arithmatex">\(\mathrm e^2\)</span></li>
    <li value="6"><strong class="auto-resultat">Réponse C</strong> : défavorable au joueur</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Dans un QCM cumulatif, identifier le chapitre n'est qu'une étape. Utiliser les réponses proposées pour vérifier la cohérence.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> La rapidité ne remplace pas le contrôle mathématique.</div>
