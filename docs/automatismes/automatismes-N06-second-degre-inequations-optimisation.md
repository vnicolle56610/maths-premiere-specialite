## Série A — Signe, intervalles et méthodes courtes

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Répondre sans rédiger un tableau complet.
</div>

<ol class="auto-questions">
<li value="1">Racines de <span class="arithmatex">\((x+2)(x-5)\)</span>.</li>
<li value="2">Signe de <span class="arithmatex">\((x+2)(x-5)\)</span> sur <span class="arithmatex">\(]-2;5[\)</span>.</li>
<li value="3">Résoudre <span class="arithmatex">\((x-3)(x+1)\leqslant0\)</span>.</li>
<li value="4">Résoudre <span class="arithmatex">\((x-4)^2&lt;0\)</span>.</li>
<li value="5">Écrire <span class="arithmatex">\(x\in[-1;6[\)</span> sous forme d'inégalité.</li>
<li value="6">Factoriser <span class="arithmatex">\(x^2-7x+12\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Lire les racines dans les facteurs.</li><li>Avec un coefficient dominant positif, le signe est négatif entre les racines.</li><li>Un carré est toujours positif ou nul.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Les crochets dépendent du symbole.</li><li>Une inéquation impossible a pour solution <span class="arithmatex">\(\varnothing\)</span>.</li></ul>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\boxed{x=-2}\)</span> et <span class="arithmatex">\(\boxed{x=5}\)</span>.</li>
    <li value="2">Le signe est <span class="arithmatex">\(\boxed{-}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\boxed{\mathscr S=[-1;3]}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(\boxed{\mathscr S=\varnothing}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(\boxed{-1\leqslant x&lt;6}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(\boxed{x^2-7x+12=(x-3)(x-4)}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Racines, signe, puis lecture du symbole. Avant <span class="arithmatex">\(\Delta\)</span>, chercher une factorisation immédiate.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Pour <span class="arithmatex">\(P(x)\leqslant0\)</span>, les racines sont incluses. Pour <span class="arithmatex">\(P(x)&lt;0\)</span>, elles sont exclues.</div>

## Série B — Comparaison et forme canonique

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Calculer ou conclure rapidement.
</div>

<ol class="auto-questions">
<li value="1">Simplifier <span class="arithmatex">\((x^2-3x+1)-(2x+1)\)</span>.</li>
<li value="2">Résoudre <span class="arithmatex">\(x(x-5)\leqslant0\)</span>.</li>
<li value="3">Extremum de <span class="arithmatex">\(2(x-4)^2-7\)</span>.</li>
<li value="4">Extremum de <span class="arithmatex">\(-3(x+2)^2+5\)</span>.</li>
<li value="5">Sommet de <span class="arithmatex">\(x\mapsto x^2-6x+4\)</span>.</li>
<li value="6">Vrai ou faux : <span class="arithmatex">\(f(x)\leqslant g(x)\Longleftrightarrow\)</span><wbr><span class="arithmatex">\( f(x)-g(x)\leqslant0\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Regrouper les termes de même degré.</li><li>Dans <span class="arithmatex">\(a(x-\alpha)^2+\beta\)</span>, lire <span class="arithmatex">\(\alpha,\beta\)</span>.</li><li>Pour comparer, étudier une différence.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Dans <span class="arithmatex">\(x+2=x-(-2)\)</span>, l'abscisse du sommet est <span class="arithmatex">\(-2\)</span>.</li><li>Le signe de <span class="arithmatex">\(a\)</span> décide minimum ou maximum.</li></ul>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(x^2-5x=\boxed{x(x-5)}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(\boxed{\mathscr S=[0;5]}\)</span>.</li>
    <li value="3">Minimum <span class="arithmatex">\(\boxed{-7}\)</span>, atteint en <span class="arithmatex">\(\boxed{x=4}\)</span>.</li>
    <li value="4">Maximum <span class="arithmatex">\(\boxed{5}\)</span>, atteint en <span class="arithmatex">\(\boxed{x=-2}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(x^2-6x+4=(x-3)^2-5\)</span>, donc <span class="arithmatex">\(\boxed{S(3;-5)}\)</span>.</li>
    <li value="6"><strong class="auto-resultat">Vrai</strong>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> La différence <span class="arithmatex">\(f-g\)</span> rassemble la comparaison en une seule étude de signe. La forme canonique donne l'extremum.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Un sommet doit être donné avec ses deux coordonnées.</div>

## Série C — Domaines et optimisation

<p class="auto-meta">⏱ 8 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Donner le domaine ou le résultat demandé.
</div>

<ol class="auto-questions">
<li value="1">Si un rectangle a pour côtés <span class="arithmatex">\(x\)</span> et <span class="arithmatex">\(12-x\)</span>, domaine de <span class="arithmatex">\(x\)</span>.</li>
<li value="2">Mettre <span class="arithmatex">\(x(12-x)\)</span> sous forme canonique.</li>
<li value="3">Aire maximale correspondante.</li>
<li value="4">Résoudre <span class="arithmatex">\(x(12-x)\geqslant27\)</span> sur <span class="arithmatex">\([0;12]\)</span>.</li>
<li value="5">Pour <span class="arithmatex">\(P(x)=2x^2-5x-3\)</span>, calculer <span class="arithmatex">\(\Delta\)</span>.</li>
<li value="6">Racines de <span class="arithmatex">\(P\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Une longueur doit être positive.</li><li>Compléter le carré ou reconnaître le sommet.</li><li>Intersecter la solution avec le domaine.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Le domaine précède l'optimisation.</li><li>Prendre <span class="arithmatex">\(b=-5\)</span>, avec son signe.</li></ul>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\boxed{x\in]0;12[}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(x(12-x)=\)</span><wbr><span class="arithmatex">\(\boxed{-(x-6)^2+36}\)</span>.</li>
    <li value="3">Aire maximale <span class="arithmatex">\(\boxed{36}\)</span>, pour <span class="arithmatex">\(\boxed{x=6}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(\boxed{\mathscr S=[3;9]}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(\Delta=\)</span><wbr><span class="arithmatex">\((-5)^2-4\times2\times(-3)=\)</span><wbr><span class="arithmatex">\(\boxed{49}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(\boxed{x=-\frac12}\)</span> ou <span class="arithmatex">\(\boxed{x=3}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Variable, domaine, modèle, forme canonique pour l'extremum, forme factorisée pour les seuils.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Une réponse d'optimisation doit mentionner l'unité et les dimensions dans le problème complet.</div>

## Série D — QCM cumulatif N01, N02, N05 et N06

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Choisir une seule réponse.
</div>

<ol class="auto-questions">
<li value="1"><span class="arithmatex">\((x-2)(x-7)\geqslant0\)</span> :<ol class="auto-choix" type="A"><li><span class="arithmatex">\([2;7]\)</span></li><li><span class="arithmatex">\(]-\infty;2]\cup[7;+\infty[\)</span></li><li><span class="arithmatex">\(]2;7[\)</span></li></ol></li>
<li value="2">Maximum de <span class="arithmatex">\(-2(x-3)^2+8\)</span> :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(-2\)</span></li><li><span class="arithmatex">\(3\)</span></li><li><span class="arithmatex">\(8\)</span></li></ol></li>
<li value="3">Si <span class="arithmatex">\(\Delta&lt;0\)</span> et <span class="arithmatex">\(a&lt;0\)</span>, le trinôme est :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(&gt;0\)</span></li><li><span class="arithmatex">\(&lt;0\)</span></li><li>variable</li></ol></li>
<li value="4"><span class="arithmatex">\(f\leqslant g\)</span> équivaut à :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(f-g\leqslant0\)</span></li><li><span class="arithmatex">\(f+g\leqslant0\)</span></li><li><span class="arithmatex">\(f-g\geqslant0\)</span></li></ol></li>
<li value="5">Domaine de <span class="arithmatex">\(x(20-2x)\)</span> pour deux longueurs positives :<ol class="auto-choix" type="A"><li><span class="arithmatex">\([0;10]\)</span></li><li><span class="arithmatex">\(]0;10[\)</span></li><li><span class="arithmatex">\(\mathbb R\)</span></li></ol></li>
<li value="6"><span class="arithmatex">\((x-1)^2&gt;0\)</span> :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(\mathbb R\)</span></li><li><span class="arithmatex">\(\mathbb R\setminus\{1\}\)</span></li><li><span class="arithmatex">\(\varnothing\)</span></li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Lire le symbole avant les crochets.</li><li>Contrôler domaine et signe de <span class="arithmatex">\(a\)</span>.</li><li>Éliminer les réponses incompatibles.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Une racine double est exclue pour une inégalité stricte.</li><li>Une longueur nulle ne construit pas un rectangle.</li></ul>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">Réponse B</strong> : Signe positif à l'extérieur.</li>
    <li value="2"><strong class="auto-resultat">Réponse C</strong> : Le maximum vaut <span class="arithmatex">\(8\)</span>.</li>
    <li value="3"><strong class="auto-resultat">Réponse B</strong> : Le trinôme garde le signe négatif de <span class="arithmatex">\(a\)</span>.</li>
    <li value="4"><strong class="auto-resultat">Réponse A</strong> : On étudie <span class="arithmatex">\(f-g\)</span>.</li>
    <li value="5"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\(x&gt;0\)</span> et <span class="arithmatex">\(20-2x&gt;0\)</span>.</li>
    <li value="6"><strong class="auto-resultat">Réponse B</strong> : Le carré s'annule seulement en <span class="arithmatex">\(1\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Le QCM vérifie des réflexes : signe, forme canonique, comparaison, domaine et inégalité stricte.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Une réponse rapide reste contrôlée par une propriété précise.</div>
