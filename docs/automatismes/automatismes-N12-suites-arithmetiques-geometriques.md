## Série A — Réactivation : termes de suites

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Calculer les termes suivants et reconnaître l'évolution.
</div>

<ol class="auto-questions">
<li value="1"><span class="arithmatex">\(u_0=4\)</span>, <span class="arithmatex">\(u_{n+1}=u_n+6\)</span>. Calculer <span class="arithmatex">\(u_1\)</span>.</li>
<li value="2">Pour la même suite, calculer <span class="arithmatex">\(u_2\)</span>.</li>
<li value="3"><span class="arithmatex">\(v_0=3\)</span>, <span class="arithmatex">\(v_{n+1}=2v_n\)</span>. Calculer <span class="arithmatex">\(v_1\)</span>.</li>
<li value="4">Pour la même suite, calculer <span class="arithmatex">\(v_2\)</span>.</li>
<li value="5">Suite <span class="arithmatex">\(5;8;11;14;\ldots\)</span>. Nature probable ?</li>
<li value="6">Suite <span class="arithmatex">\(2;6;18;54;\ldots\)</span>. Nature probable ?</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Addition constante : arithmétique.</li><li>Multiplication constante : géométrique.</li><li>Comparer deux termes consécutifs.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Une suite géométrique ne s'obtient pas par addition.</li><li>La raison peut être négative ou fractionnaire.</li></ul>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(u_1=4+6=\boxed{10}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(u_2=10+6=\boxed{16}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(v_1=2\times3=\boxed{6}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(v_2=2\times6=\boxed{12}\)</span>.</li>
    <li value="5">On ajoute <span class="arithmatex">\(3\)</span> : <span class="arithmatex">\(\boxed{\text{suite arithmétique}}\)</span>, raison <span class="arithmatex">\(3\)</span>.</li>
    <li value="6">On multiplie par <span class="arithmatex">\(3\)</span> : <span class="arithmatex">\(\boxed{\text{suite géométrique}}\)</span>, raison <span class="arithmatex">\(3\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> La nature se lit sur le passage d'un terme au suivant : différence ou quotient constant.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Ne pas décider avec un seul écart : vérifier plusieurs passages si possible.</div>

## Série B — Suites arithmétiques

<p class="auto-meta">⏱ 8 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Utiliser les formules d'une suite arithmétique.
</div>

<ol class="auto-questions">
<li value="1"><span class="arithmatex">\(u_0=7\)</span>, raison <span class="arithmatex">\(r=4\)</span>. Calculer <span class="arithmatex">\(u_5\)</span>.</li>
<li value="2"><span class="arithmatex">\(v_1=10\)</span>, raison <span class="arithmatex">\(r=-2\)</span>. Calculer <span class="arithmatex">\(v_4\)</span>.</li>
<li value="3">Suite arithmétique : <span class="arithmatex">\(a_2=9\)</span>, raison <span class="arithmatex">\(3\)</span>. Calculer <span class="arithmatex">\(a_5\)</span>.</li>
<li value="4"><span class="arithmatex">\(u_0=5\)</span>, <span class="arithmatex">\(u_6=23\)</span>. Trouver la raison.</li>
<li value="5"><span class="arithmatex">\(w_n=12-5n\)</span>. Donner la raison.</li>
<li value="6">Une suite arithmétique a <span class="arithmatex">\(u_3=20\)</span> et <span class="arithmatex">\(u_4=17\)</span>. Donner <span class="arithmatex">\(r\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Formule : <span class="arithmatex">\(u_n=u_0+nr\)</span>.</li><li>Entre deux rangs : ajouter <span class="arithmatex">\((n-p)r\)</span>.</li><li>La raison est <span class="arithmatex">\(u_{n+1}-u_n\)</span>.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Si la suite commence à <span class="arithmatex">\(1\)</span>, adapter la formule.</li><li>La raison n'est pas toujours positive.</li></ul>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(u_5=\)</span><wbr><span class="arithmatex">\(7+5\times4=\)</span><wbr><span class="arithmatex">\(\boxed{27}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(v_4=\)</span><wbr><span class="arithmatex">\(v_1+3r=\)</span><wbr><span class="arithmatex">\(10+3\times(-2)=\)</span><wbr><span class="arithmatex">\(\boxed{4}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(a_5=\)</span><wbr><span class="arithmatex">\(a_2+3r=\)</span><wbr><span class="arithmatex">\(9+3\times3=\)</span><wbr><span class="arithmatex">\(\boxed{18}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(23=5+6r\)</span>, donc <span class="arithmatex">\(6r=18\)</span> et <span class="arithmatex">\(\boxed{r=3}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(w_{n+1}-w_n=\)</span><wbr><span class="arithmatex">\((12-5n-5)-(12-5n)=\)</span><wbr><span class="arithmatex">\(\boxed{-5}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(r=\)</span><wbr><span class="arithmatex">\(u_4-u_3=\)</span><wbr><span class="arithmatex">\(17-20=\)</span><wbr><span class="arithmatex">\(\boxed{-3}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Pour une suite arithmétique, on ajoute toujours la même quantité.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Attention au nombre de pas : de <span class="arithmatex">\(v_1\)</span> à <span class="arithmatex">\(v_4\)</span>, il y a <span class="arithmatex">\(3\)</span> pas.</div>

## Série C — Suites géométriques

<p class="auto-meta">⏱ 8 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Utiliser les formules d'une suite géométrique.
</div>

<ol class="auto-questions">
<li value="1"><span class="arithmatex">\(u_0=3\)</span>, raison <span class="arithmatex">\(q=2\)</span>. Calculer <span class="arithmatex">\(u_4\)</span>.</li>
<li value="2"><span class="arithmatex">\(v_1=5\)</span>, raison <span class="arithmatex">\(q=3\)</span>. Calculer <span class="arithmatex">\(v_3\)</span>.</li>
<li value="3">Suite géométrique : <span class="arithmatex">\(a_2=8\)</span>, raison <span class="arithmatex">\(\dfrac12\)</span>. Calculer <span class="arithmatex">\(a_5\)</span>.</li>
<li value="4"><span class="arithmatex">\(u_0=4\)</span>, <span class="arithmatex">\(u_3=108\)</span>. Trouver la raison positive.</li>
<li value="5"><span class="arithmatex">\(w_n=7\times 0{,}8^n\)</span>. Donner la raison.</li>
<li value="6">Une quantité baisse de <span class="arithmatex">\(15\,\%\)</span> par étape. Donner le coefficient multiplicateur.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Formule : <span class="arithmatex">\(u_n=u_0q^n\)</span>.</li><li>Entre deux rangs : multiplier par <span class="arithmatex">\(q^{n-p}\)</span>.</li><li>Une baisse de <span class="arithmatex">\(t\%\)</span> donne <span class="arithmatex">\(1-\frac{t}{100}\)</span>.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Ne pas confondre raison et terme initial.</li><li>Une évolution en pourcentage se modélise souvent géométriquement.</li></ul>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(u_4=\)</span><wbr><span class="arithmatex">\(3\times2^4=\)</span><wbr><span class="arithmatex">\(3\times16=\)</span><wbr><span class="arithmatex">\(\boxed{48}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(v_3=\)</span><wbr><span class="arithmatex">\(v_1\times3^2=\)</span><wbr><span class="arithmatex">\(5\times9=\)</span><wbr><span class="arithmatex">\(\boxed{45}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(a_5=\)</span><wbr><span class="arithmatex">\(a_2\left(\dfrac12\right)^3=\)</span><wbr><span class="arithmatex">\(8\times\dfrac18=\)</span><wbr><span class="arithmatex">\(\boxed{1}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(108=4q^3\)</span>, donc <span class="arithmatex">\(q^3=27\)</span> et <span class="arithmatex">\(\boxed{q=3}\)</span>.</li>
    <li value="5">Dans <span class="arithmatex">\(w_n=7\times0{,}8^n\)</span>, la raison est <span class="arithmatex">\(\boxed{0{,}8}\)</span>.</li>
    <li value="6">Baisser de <span class="arithmatex">\(15\,\%\)</span> revient à multiplier par <span class="arithmatex">\(\boxed{0{,}85}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Pour une suite géométrique, on multiplie toujours par le même nombre.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Une baisse ne signifie pas raison négative : le coefficient est souvent entre <span class="arithmatex">\(0\)</span> et <span class="arithmatex">\(1\)</span>.</div>

## Série D — Type épreuve anticipée : QCM

<p class="auto-meta">⏱ 5 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Choisir une seule réponse. Aucune justification n'est demandée.
</div>

<ol class="auto-questions">
<li value="1"><span class="arithmatex">\(u_n=5+2n\)</span>. Nature :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(arithmétique\)</span></li><li><span class="arithmatex">\(géométrique\)</span></li><li><span class="arithmatex">\(constante\)</span></li><li><span class="arithmatex">\(aucune\)</span></li></ol></li>
<li value="2"><span class="arithmatex">\(v_n=4\times3^n\)</span>. Raison :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(4\)</span></li><li><span class="arithmatex">\(3\)</span></li><li><span class="arithmatex">\(12\)</span></li><li><span class="arithmatex">\(n\)</span></li></ol></li>
<li value="3">Suite arithmétique <span class="arithmatex">\(u_0=2\)</span>, <span class="arithmatex">\(r=5\)</span>. <span class="arithmatex">\(u_3=\)</span><ol class="auto-choix" type="A"><li><span class="arithmatex">\(7\)</span></li><li><span class="arithmatex">\(10\)</span></li><li><span class="arithmatex">\(15\)</span></li><li><span class="arithmatex">\(17\)</span></li></ol></li>
<li value="4">Suite géométrique <span class="arithmatex">\(v_0=2\)</span>, <span class="arithmatex">\(q=5\)</span>. <span class="arithmatex">\(v_3=\)</span><ol class="auto-choix" type="A"><li><span class="arithmatex">\(15\)</span></li><li><span class="arithmatex">\(30\)</span></li><li><span class="arithmatex">\(125\)</span></li><li><span class="arithmatex">\(250\)</span></li></ol></li>
<li value="5">Augmenter de <span class="arithmatex">\(8\,\%\)</span>, c'est multiplier par :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(0{,}08\)</span></li><li><span class="arithmatex">\(0{,}92\)</span></li><li><span class="arithmatex">\(1{,}08\)</span></li><li><span class="arithmatex">\(8\)</span></li></ol></li>
<li value="6">Si <span class="arithmatex">\(u_{n+1}=u_n-4\)</span>, la raison est :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(-4\)</span></li><li><span class="arithmatex">\(4\)</span></li><li><span class="arithmatex">\(u_n\)</span></li><li><span class="arithmatex">\(n-4\)</span></li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Lire la forme de la formule.</li><li><span class="arithmatex">\(a+nr\)</span> : arithmétique.</li><li><span class="arithmatex">\(a q^n\)</span> : géométrique.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Dans <span class="arithmatex">\(a q^n\)</span>, <span class="arithmatex">\(a\)</span> n'est pas la raison.</li><li>Un pourcentage d'augmentation donne un coefficient <span class="arithmatex">\(&gt;1\)</span>.</li></ul>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">Réponse A</strong> : Forme <span class="arithmatex">\(u_0+nr\)</span>.</li>
    <li value="2"><strong class="auto-resultat">Réponse B</strong> : Dans <span class="arithmatex">\(4\times3^n\)</span>, la raison est <span class="arithmatex">\(3\)</span>.</li>
    <li value="3"><strong class="auto-resultat">Réponse D</strong> : <span class="arithmatex">\(u_3=2+3\times5=17\)</span>.</li>
    <li value="4"><strong class="auto-resultat">Réponse D</strong> : <span class="arithmatex">\(v_3=2\times5^3=250\)</span>.</li>
    <li value="5"><strong class="auto-resultat">Réponse C</strong> : <span class="arithmatex">\(1+0{,}08=1{,}08\)</span>.</li>
    <li value="6"><strong class="auto-resultat">Réponse A</strong> : On ajoute toujours <span class="arithmatex">\(-4\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Repérer le modèle avant de calculer : addition répétée ou multiplication répétée.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Le nombre de pas dépend du rang initial indiqué dans l'énoncé.</div>
