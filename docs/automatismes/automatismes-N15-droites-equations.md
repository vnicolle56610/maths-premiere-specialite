## Série A — Lire une équation de droite

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Extraire rapidement des informations d'une équation cartésienne ou réduite.
</div>

<ol class="auto-questions">
<li value="1">Dans <span class="arithmatex">\(y=2x-5\)</span>, quel est le coefficient directeur ?</li>
<li value="2">Dans <span class="arithmatex">\(y=-3x+4\)</span>, quelle est l'ordonnée à l'origine ?</li>
<li value="3">Le point <span class="arithmatex">\(A(3;1)\)</span> appartient-il à la droite <span class="arithmatex">\(y=2x-5\)</span> ?</li>
<li value="4">Sur la droite <span class="arithmatex">\(y=3x+1\)</span>, quelle est l'ordonnée du point d'abscisse <span class="arithmatex">\(2\)</span> ?</li>
<li value="5">Donner un vecteur directeur de la droite <span class="arithmatex">\(y=2x-1\)</span>.</li>
<li value="6">Donner un vecteur normal à la droite <span class="arithmatex">\(3x-2y+5=0\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Dans <span class="arithmatex">\(y=mx+p\)</span>, <span class="arithmatex">\(m\)</span> est le coefficient directeur.</li><li>Tester un point : remplacer <span class="arithmatex">\(x\)</span> et <span class="arithmatex">\(y\)</span>.</li><li>Pour <span class="arithmatex">\(ax+by+c=0\)</span>, <span class="arithmatex">\((a;b)\)</span> est normal.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Un vecteur directeur n'est pas un point.</li><li>Vérifier la nature des objets : point, vecteur, nombre.</li></ul>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1">Le coefficient directeur est <span class="arithmatex">\(\boxed{2}\)</span>.</li>
    <li value="2">L'ordonnée à l'origine est <span class="arithmatex">\(\boxed{4}\)</span>.</li>
    <li value="3">Pour <span class="arithmatex">\(x=3\)</span>, <span class="arithmatex">\(2x-5=1\)</span>. Donc <span class="arithmatex">\(A\)</span> <span class="arithmatex">\(\boxed{\text{appartient}}\)</span> à la droite.</li>
    <li value="4"><span class="arithmatex">\(y=3\times2+1=\boxed{7}\)</span>.</li>
    <li value="5">Un vecteur directeur est <span class="arithmatex">\(\boxed{(1;2)}\)</span>.</li>
    <li value="6">Un vecteur normal est <span class="arithmatex">\(\boxed{(3;-2)}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Une équation de droite donne des informations de nature différente : nombre, point, vecteur.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Ne pas confondre vecteur directeur <span class="arithmatex">\((1;m)\)</span> et vecteur normal <span class="arithmatex">\((a;b)\)</span>.</div>

## Série B — Déterminer une équation

<p class="auto-meta">⏱ 8 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Trouver une équation de droite à partir de données simples.
</div>

<ol class="auto-questions">
<li value="1">Droite de coefficient directeur <span class="arithmatex">\(3\)</span> passant par <span class="arithmatex">\(A(0;2)\)</span>. Équation réduite ?</li>
<li value="2">Droite de coefficient directeur <span class="arithmatex">\(-1\)</span> passant par <span class="arithmatex">\(B(2;5)\)</span>. Équation réduite ?</li>
<li value="3">Droite passant par <span class="arithmatex">\(A(1;2)\)</span> et <span class="arithmatex">\(B(3;6)\)</span>. Coefficient directeur ?</li>
<li value="4">Pour les mêmes points, donner une équation réduite.</li>
<li value="5">Droite horizontale passant par <span class="arithmatex">\(C(4;-2)\)</span>. Équation ?</li>
<li value="6">Droite verticale passant par <span class="arithmatex">\(D(5;1)\)</span>. Équation ?</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Utiliser <span class="arithmatex">\(m=\)</span><wbr><span class="arithmatex">\(\dfrac{y_B-y_A}{x_B-x_A}\)</span>.</li><li>Puis écrire <span class="arithmatex">\(y=mx+p\)</span>.</li><li>Horizontale : <span class="arithmatex">\(y=\)</span> constante ; verticale : <span class="arithmatex">\(x=\)</span> constante.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Une droite verticale n'a pas d'équation réduite.</li><li>Garder des égalités entre objets de même nature.</li></ul>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1">Comme <span class="arithmatex">\(p=2\)</span>, l'équation est <span class="arithmatex">\(\boxed{y=3x+2}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(5=-2+p\)</span>, donc <span class="arithmatex">\(p=7\)</span>. Équation : <span class="arithmatex">\(\boxed{y=-x+7}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(m=\)</span><wbr><span class="arithmatex">\(\dfrac{6-2}{3-1}=\)</span><wbr><span class="arithmatex">\(\dfrac42=\)</span><wbr><span class="arithmatex">\(\boxed{2}\)</span>.</li>
    <li value="4">Avec <span class="arithmatex">\(A(1;2)\)</span>, <span class="arithmatex">\(2=2\times1+p\)</span>, donc <span class="arithmatex">\(p=0\)</span>. Équation : <span class="arithmatex">\(\boxed{y=2x}\)</span>.</li>
    <li value="5">Droite horizontale : <span class="arithmatex">\(\boxed{y=-2}\)</span>.</li>
    <li value="6">Droite verticale : <span class="arithmatex">\(\boxed{x=5}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Le coefficient directeur compare deux variations : variation de <span class="arithmatex">\(y\)</span> divisée par variation de <span class="arithmatex">\(x\)</span>.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Si les abscisses sont égales, la formule du coefficient directeur n'est pas utilisable.</div>

## Série C — Positions relatives et intersections

<p class="auto-meta">⏱ 8 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Reconnaître parallélisme, intersection et perpendicularité dans des cas simples.
</div>

<ol class="auto-questions">
<li value="1">Les droites <span class="arithmatex">\(y=2x+1\)</span> et <span class="arithmatex">\(y=2x-3\)</span> sont-elles parallèles ?</li>
<li value="2">Les droites <span class="arithmatex">\(y=3x+1\)</span> et <span class="arithmatex">\(y=-\dfrac13x+2\)</span> sont-elles perpendiculaires ?</li>
<li value="3">Résoudre <span class="arithmatex">\(2x+1=-x+7\)</span>.</li>
<li value="4">En déduire l'abscisse du point d'intersection de <span class="arithmatex">\(y=2x+1\)</span> et <span class="arithmatex">\(y=-x+7\)</span>.</li>
<li value="5">Calculer son ordonnée.</li>
<li value="6">Les droites <span class="arithmatex">\(x=4\)</span> et <span class="arithmatex">\(y=-1\)</span> se coupent-elles ?</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Parallèles : mêmes coefficients directeurs.</li><li>Perpendiculaires : produit des coefficients directeurs égal à <span class="arithmatex">\(-1\)</span>.</li><li>Intersection : résoudre l'égalité des deux expressions de <span class="arithmatex">\(y\)</span>.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Deux droites parallèles distinctes n'ont pas de point commun.</li><li>Le point d'intersection a deux coordonnées.</li></ul>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1">Oui, elles ont le même coefficient directeur <span class="arithmatex">\(2\)</span> : <span class="arithmatex">\(\boxed{\text{parallèles}}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(3\times\left(-\dfrac13\right)=\)</span><wbr><span class="arithmatex">\(-1\)</span>, donc elles sont <span class="arithmatex">\(\boxed{\text{perpendiculaires}}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(2x+1=-x+7 \Longleftrightarrow\)</span><wbr><span class="arithmatex">\( 3x=6 \Longleftrightarrow\)</span><wbr><span class="arithmatex">\( x=\boxed{2}\)</span>.</li>
    <li value="4">L'abscisse du point d'intersection est <span class="arithmatex">\(\boxed{2}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(y=2\times2+1=\boxed{5}\)</span>. Le point est <span class="arithmatex">\((2;5)\)</span>.</li>
    <li value="6">Oui, elles se coupent au point <span class="arithmatex">\(\boxed{(4;-1)}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Pour trouver une intersection, on résout une équation puis on calcule l'autre coordonnée.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Ne pas s'arrêter à <span class="arithmatex">\(x=2\)</span> si l'on demande un point.</div>

## Série D — QCM : droites

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Choisir la seule réponse correcte.
</div>

<ol class="auto-questions">
<li value="1">Un vecteur directeur de <span class="arithmatex">\(y=-4x+1\)</span> est<ol class="auto-choix" type="A"><li><span class="arithmatex">\((1;-4)\)</span></li><li><span class="arithmatex">\((-4;1)\)</span></li><li><span class="arithmatex">\((1;1)\)</span></li></ol></li>
<li value="2">La droite <span class="arithmatex">\(2x+5=0\)</span> a pour équation<ol class="auto-choix" type="A"><li><span class="arithmatex">\(x=-\dfrac52\)</span></li><li><span class="arithmatex">\(y=-\dfrac52\)</span></li><li><span class="arithmatex">\(x=\dfrac52\)</span></li></ol></li>
<li value="3"><span class="arithmatex">\(A(1;4)\)</span> est sur <span class="arithmatex">\(y=3x+1\)</span> ?<ol class="auto-choix" type="A"><li>oui</li><li>non</li><li>impossible à savoir</li></ol></li>
<li value="4">Deux droites de coefficients directeurs <span class="arithmatex">\(5\)</span> et <span class="arithmatex">\(5\)</span> sont<ol class="auto-choix" type="A"><li>sécantes</li><li>parallèles</li><li>perpendiculaires</li></ol></li>
<li value="5">Un vecteur normal à <span class="arithmatex">\(x+2y-3=0\)</span> est<ol class="auto-choix" type="A"><li><span class="arithmatex">\((1;2)\)</span></li><li><span class="arithmatex">\((2;-1)\)</span></li><li><span class="arithmatex">\((1;-3)\)</span></li></ol></li>
<li value="6">La droite <span class="arithmatex">\(y=-2\)</span> est<ol class="auto-choix" type="A"><li>verticale</li><li>horizontale</li><li>oblique</li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Identifier d'abord la forme de l'équation.</li><li>Tester les propositions rapidement.</li><li>Distinguer vecteur normal et vecteur directeur.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Une droite <span class="arithmatex">\(x=a\)</span> est verticale.</li><li>Une droite <span class="arithmatex">\(y=b\)</span> est horizontale.</li></ul>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">Réponse A</strong> : Pour <span class="arithmatex">\(m=-4\)</span>, un vecteur directeur est <span class="arithmatex">\((1;-4)\)</span> : réponse .</li>
    <li value="2"><strong class="auto-resultat">Réponse A</strong> : <span class="arithmatex">\(2x+5=0 \Longleftrightarrow\)</span><wbr><span class="arithmatex">\( x=-\dfrac52\)</span> : réponse .</li>
    <li value="3"><strong class="auto-resultat">Réponse A</strong> : <span class="arithmatex">\(3\times1+1=4\)</span>, donc oui : réponse .</li>
    <li value="4"><strong class="auto-resultat">Réponse B</strong> : Même coefficient directeur : droites parallèles ou confondues ; réponse .</li>
    <li value="5"><strong class="auto-resultat">Réponse A</strong> : Pour <span class="arithmatex">\(x+2y-3=0\)</span>, un vecteur normal est <span class="arithmatex">\((1;2)\)</span> : réponse .</li>
    <li value="6"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\(y=-2\)</span> est horizontale : réponse .</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Le QCM se traite en repérant les invariants : coefficient directeur, point, vecteur normal.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Même coefficient directeur ne signifie pas forcément même droite.</div>
