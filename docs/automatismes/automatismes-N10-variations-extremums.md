## Série A — Réactiver les dérivées

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Calculer rapidement les dérivées et les valeurs demandées.
</div>

<ol class="auto-questions">
<li value="1"><span class="arithmatex">\(f(x)=x^2-4x+1\)</span>. Calculer <span class="arithmatex">\(f'(x)\)</span>.</li>
<li value="2"><span class="arithmatex">\(g(x)=-x^2+6x+2\)</span>. Calculer <span class="arithmatex">\(g'(x)\)</span>.</li>
<li value="3">Résoudre <span class="arithmatex">\(2x-4=0\)</span>.</li>
<li value="4">Donner le signe de <span class="arithmatex">\(x-3\)</span> sur <span class="arithmatex">\((-\infty;3)\)</span>.</li>
<li value="5"><span class="arithmatex">\(h(x)=x^3-3x\)</span>. Calculer <span class="arithmatex">\(h'(1)\)</span>.</li>
<li value="6"><span class="arithmatex">\(p(x)=\dfrac1x\)</span>. Calculer <span class="arithmatex">\(p'(2)\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Une étude de variations commence par une dérivée.</li><li>Résoudre <span class="arithmatex">\(f'(x)=0\)</span> donne les candidats extremums.</li><li>Le signe d'une expression affine se lit autour de sa racine.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Ne pas confondre <span class="arithmatex">\(f(x)\)</span> et <span class="arithmatex">\(f'(x)\)</span>.</li><li>Un extremum dépend aussi de l'intervalle étudié.</li></ul>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\boxed{f'(x)=2x-4}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(\boxed{g'(x)=-2x+6}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(2x-4=0 \iff\)</span><wbr><span class="arithmatex">\( 2x=4 \iff\)</span><wbr><span class="arithmatex">\( \boxed{x=2}\)</span>.</li>
    <li value="4">Si <span class="arithmatex">\(x&lt;3\)</span>, alors <span class="arithmatex">\(x-3&lt;0\)</span>. Signe : <span class="arithmatex">\(\boxed{-}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(h'(x)=3x^2-3\)</span>, donc <span class="arithmatex">\(h'(1)=\boxed{0}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(p'(x)=-\dfrac1{x^2}\)</span>, donc <span class="arithmatex">\(p'(2)=\boxed{-\dfrac14}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Pour étudier les variations, on calcule <span class="arithmatex">\(f'\)</span>, on étudie son signe, puis on conclut sur <span class="arithmatex">\(f\)</span>.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Un nombre dérivé nul ne suffit pas toujours à conclure à un extremum.</div>

## Série B — Signe de <span class="arithmatex">\(f'\)</span> et variations

<p class="auto-meta">⏱ 8 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Passer du signe de la dérivée au sens de variation de la fonction.
</div>

<ol class="auto-questions">
<li value="1"><span class="arithmatex">\(f'(x)=2x-4\)</span>. Variations de <span class="arithmatex">\(f\)</span> sur <span class="arithmatex">\(\mathbb R\)</span>.</li>
<li value="2"><span class="arithmatex">\(g'(x)=-3x+6\)</span>. Variations de <span class="arithmatex">\(g\)</span> sur <span class="arithmatex">\(\mathbb R\)</span>.</li>
<li value="3"><span class="arithmatex">\(h'(x)=(x-1)(x+3)\)</span>. Signe de <span class="arithmatex">\(h'\)</span> sur <span class="arithmatex">\(\mathbb R\)</span>.</li>
<li value="4"><span class="arithmatex">\(u(x)=x^2-4x+1\)</span>. Donner l'extremum sur <span class="arithmatex">\(\mathbb R\)</span>.</li>
<li value="5"><span class="arithmatex">\(v(x)=-x^2+6x+2\)</span>. Donner l'extremum sur <span class="arithmatex">\(\mathbb R\)</span>.</li>
<li value="6">Si <span class="arithmatex">\(w'(x)=x^2+1\)</span>, que peut-on dire des variations de <span class="arithmatex">\(w\)</span> ?</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li><span class="arithmatex">\(f'&gt;0\)</span> : la fonction augmente.</li><li><span class="arithmatex">\(f'&lt;0\)</span> : la fonction diminue.</li><li>Chercher d'abord les zéros de <span class="arithmatex">\(f'\)</span>.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Le signe de <span class="arithmatex">\(f'\)</span>, pas celui de <span class="arithmatex">\(f\)</span>, donne les variations.</li><li>Un extremum local correspond souvent à un changement de signe de <span class="arithmatex">\(f'\)</span>.</li></ul>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(2x-4=0\iff x=2\)</span>. <span class="arithmatex">\(f'&lt;0\)</span> si <span class="arithmatex">\(x&lt;2\)</span>, <span class="arithmatex">\(f'&gt;0\)</span> si <span class="arithmatex">\(x&gt;2\)</span>. Donc <span class="arithmatex">\(f\)</span> décroît puis croît.</li>
    <li value="2"><span class="arithmatex">\(-3x+6=0\iff x=2\)</span>. <span class="arithmatex">\(g'&gt;0\)</span> si <span class="arithmatex">\(x&lt;2\)</span>, <span class="arithmatex">\(g'&lt;0\)</span> si <span class="arithmatex">\(x&gt;2\)</span>. Donc <span class="arithmatex">\(g\)</span> croît puis décroît.</li>
    <li value="3">Les zéros sont <span class="arithmatex">\(-3\)</span> et <span class="arithmatex">\(1\)</span>. Signe : <span class="arithmatex">\(\boxed{+}\)</span> sur <span class="arithmatex">\((-\infty;-3)\cup(1;+\infty)\)</span>, <span class="arithmatex">\(\boxed{-}\)</span> sur <span class="arithmatex">\((-3;1)\)</span>.</li>
    <li value="4"><span class="arithmatex">\(u'(x)=2x-4\)</span>, donc minimum en <span class="arithmatex">\(2\)</span>. <span class="arithmatex">\(u(2)=4-8+1=\boxed{-3}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(v'(x)=-2x+6\)</span>, donc maximum en <span class="arithmatex">\(3\)</span>. <span class="arithmatex">\(v(3)=-9+18+2=\boxed{11}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(x^2+1&gt;0\)</span> pour tout réel <span class="arithmatex">\(x\)</span>. Donc <span class="arithmatex">\(w\)</span> est <span class="arithmatex">\(\boxed{\text{strictement croissante}}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Une ligne de signe de <span class="arithmatex">\(f'\)</span> se transforme en ligne de variations de <span class="arithmatex">\(f\)</span>.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Le mot « extremum » demande une valeur de la fonction, pas seulement l'abscisse.</div>

## Série C — Extremums sur intervalle

<p class="auto-meta">⏱ 8 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Identifier les valeurs candidates puis conclure sur l'intervalle demandé.
</div>

<ol class="auto-questions">
<li value="1"><span class="arithmatex">\(f(x)=x^2-4x+5\)</span> sur <span class="arithmatex">\([0;4]\)</span>. Donner le minimum.</li>
<li value="2">Pour la même fonction, donner le maximum sur <span class="arithmatex">\([0;4]\)</span>.</li>
<li value="3"><span class="arithmatex">\(g(x)=-x^2+2x+3\)</span> sur <span class="arithmatex">\([-1;4]\)</span>. Donner le maximum.</li>
<li value="4">Pour la même fonction, donner le minimum sur <span class="arithmatex">\([-1;4]\)</span>.</li>
<li value="5">Donner le minimum de <span class="arithmatex">\((x-2)^2+1\)</span> sur <span class="arithmatex">\(\mathbb R\)</span>.</li>
<li value="6">Optimisation : <span class="arithmatex">\(A(x)=x(10-2x)\)</span>, <span class="arithmatex">\(0\leq x\leq5\)</span>. Donner l'abscisse du maximum.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Sur un segment, tester aussi les bornes.</li><li>Une forme canonique donne vite l'extremum.</li><li>Pour optimiser, étudier les variations.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Un maximum sur un intervalle fermé peut être à une borne.</li><li>Ne pas conclure avec l'abscisse si la question demande la valeur.</li></ul>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(f(x)=(x-2)^2+1\)</span>. Le minimum est atteint en <span class="arithmatex">\(2\)</span> et vaut <span class="arithmatex">\(\boxed{1}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(f(0)=5\)</span> et <span class="arithmatex">\(f(4)=5\)</span>. Le maximum sur <span class="arithmatex">\([0;4]\)</span> vaut <span class="arithmatex">\(\boxed{5}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(g(x)=-(x-1)^2+4\)</span>. Le maximum vaut <span class="arithmatex">\(\boxed{4}\)</span>, atteint en <span class="arithmatex">\(1\)</span>.</li>
    <li value="4"><span class="arithmatex">\(g(-1)=0\)</span> et <span class="arithmatex">\(g(4)=-5\)</span>. Le minimum sur <span class="arithmatex">\([-1;4]\)</span> vaut <span class="arithmatex">\(\boxed{-5}\)</span>.</li>
    <li value="5"><span class="arithmatex">\((x-2)^2\geq0\)</span>, donc <span class="arithmatex">\((x-2)^2+1\geq1\)</span>. Minimum : <span class="arithmatex">\(\boxed{1}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(A(x)=-2x^2+10x\)</span>. Le sommet a pour abscisse <span class="arithmatex">\(\dfrac{-10}{2\times(-2)}=\)</span><wbr><span class="arithmatex">\(\boxed{\dfrac52}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Sur un segment, comparer les valeurs aux points critiques et aux bornes.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> L'abscisse d'un extremum et la valeur de l'extremum sont deux nombres différents.</div>

## Série D — Type épreuve anticipée : QCM

<p class="auto-meta">⏱ 5 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Choisir une seule réponse. Aucune justification n'est demandée.
</div>

<ol class="auto-questions">
<li value="1">Signe de <span class="arithmatex">\(f'\)</span> : <span class="arithmatex">\(+\)</span> puis <span class="arithmatex">\(-\)</span>. Extremum ?<ol class="auto-choix" type="A"><li>minimum ;</li><li>maximum ;</li><li>aucun ;</li><li>horizontal.</li></ol></li>
<li value="2"><span class="arithmatex">\(f'(x)=x-5\)</span>. L'extremum possible est en :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(-5\)</span></li><li><span class="arithmatex">\(0\)</span></li><li><span class="arithmatex">\(5\)</span></li><li><span class="arithmatex">\(1\)</span></li></ol></li>
<li value="3"><span class="arithmatex">\(f(x)=x^2+2x\)</span>. Le minimum sur <span class="arithmatex">\(\mathbb R\)</span> est atteint en :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(-2\)</span></li><li><span class="arithmatex">\(-1\)</span></li><li><span class="arithmatex">\(0\)</span></li><li><span class="arithmatex">\(1\)</span></li></ol></li>
<li value="4">Si <span class="arithmatex">\(f'(x)&lt;0\)</span> sur un intervalle <span class="arithmatex">\(I\)</span>, alors <span class="arithmatex">\(f\)</span> est :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(croissante\)</span></li><li><span class="arithmatex">\(décroissante\)</span></li><li><span class="arithmatex">\(constante\)</span></li><li><span class="arithmatex">\(positive\)</span></li></ol></li>
<li value="5">Sur <span class="arithmatex">\([0;3]\)</span>, <span class="arithmatex">\(x^2\)</span> a pour maximum :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(0\)</span></li><li><span class="arithmatex">\(3\)</span></li><li><span class="arithmatex">\(6\)</span></li><li><span class="arithmatex">\(9\)</span></li></ol></li>
<li value="6"><span class="arithmatex">\(f'(x)=3x^2\)</span>. Sur <span class="arithmatex">\(\mathbb R\)</span>, <span class="arithmatex">\(f\)</span> est :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(décroissante\)</span></li><li><span class="arithmatex">\(croissante\)</span></li><li><span class="arithmatex">\(constante\)</span></li><li><span class="arithmatex">\(non définie\)</span></li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Lier signe de <span class="arithmatex">\(f'\)</span> et variation de <span class="arithmatex">\(f\)</span>.</li><li>Un changement <span class="arithmatex">\(+\)</span> vers <span class="arithmatex">\(-\)</span> donne un maximum.</li><li>Sur un segment, comparer les bornes.</li></ul>
    <p><strong>Vigilance</strong></p><ul><li>Le signe de <span class="arithmatex">\(f'\)</span> ne donne pas le signe de <span class="arithmatex">\(f\)</span>.</li><li>Un QCM peut se traiter par élimination.</li></ul>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">Réponse B</strong> : La fonction croît puis décroît : maximum.</li>
    <li value="2"><strong class="auto-resultat">Réponse C</strong> : <span class="arithmatex">\(x-5=0\iff x=5\)</span>.</li>
    <li value="3"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\(x^2+2x=(x+1)^2-1\)</span>.</li>
    <li value="4"><strong class="auto-resultat">Réponse B</strong> : Si <span class="arithmatex">\(f'&lt;0\)</span>, alors <span class="arithmatex">\(f\)</span> décroît.</li>
    <li value="5"><strong class="auto-resultat">Réponse D</strong> : Sur <span class="arithmatex">\([0;3]\)</span>, <span class="arithmatex">\(x^2\)</span> est croissante et <span class="arithmatex">\(3^2=9\)</span>.</li>
    <li value="6"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\(3x^2\geq0\)</span> et ne s'annule qu'en <span class="arithmatex">\(0\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Les variations se lisent sur le signe de <span class="arithmatex">\(f'\)</span>. Pour un extremum, préciser l'abscisse et la valeur lorsque c'est demandé.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> La proposition choisie doit répondre exactement à la question posée.</div>
