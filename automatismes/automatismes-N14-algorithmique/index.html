    Automatismes N14 — Algorithmique

    24 questions sans calculatrice, réparties en 4 séries courtes à faire en quelques minutes. Chercher d'abord seul, puis ouvrir le corrigé.

    ⚡ Faire le QCM interactif 📄 Diaporama PDF à projeter 📖 Revoir la notion

    Série A — Tracer des affectations

    ⏱ 6 min · Calculatrice interdite

    Consigne. Compléter mentalement les valeurs obtenues après les instructions.

    1. \(\texttt{x=4 ; x=x+3}\). Quelle est la valeur finale de \(x\) ?
    2. \(\texttt{a=2 ; b=5 ; a=a+b}\). Quelle est la valeur finale de \(a\) ?
    3. \(\texttt{u=3}\), puis deux fois \(\texttt{u=2*u+1}\). Valeur finale ?
    4. \(\texttt{s=0}\), puis on ajoute \(2\) ; \(4\) ; \(6\). Valeur finale de \(s\) ?
    5. Dans la liste \(\texttt{L=[4,7,10]}\), que vaut \(\texttt{L[0]}\) ?
    6. Quelles valeurs prend \(k\) dans \(\texttt{range(4)}\) ?
    Coup de pouce

    Conseils

    • Une affectation remplace l'ancienne valeur.
    • Dans une liste Python, le premier indice est \(0\).
    • \(\texttt{range(n)}\) s'arrête avant \(n\).

    Vigilance

    • Lire les instructions dans l'ordre.
    • Ne pas confondre égalité mathématique et affectation informatique.

    Corrigé de la série A

    1. \(x\) vaut d'abord \(4\), puis \(4+3\), donc \(\boxed{7}\).
    2. \(a\) devient \(2+5\), donc \(\boxed{7}\).
    3. \(3\rightarrow 7\rightarrow 15\), donc la valeur finale est \(\boxed{15}\).
    4. \(s=0+2+4+6=\boxed{12}\).
    5. \(\texttt{L[0]}\) désigne le premier élément : \(\boxed{4}\).
    6. \(\texttt{range(4)}\) donne \(\boxed{0;1;2;3}\).
    Méthode. Faire une trace d'exécution : une ligne par instruction, une colonne par variable.
    Vigilance. Le symbole \(=\) en Python signifie « reçoit la valeur ».

    Série B — Boucles et répétitions

    ⏱ 8 min · Calculatrice interdite

    Consigne. Déterminer le résultat obtenu après une boucle courte.

    1. \(u=5\). On répète trois fois : \(u\leftarrow u+4\). Valeur finale ?
    2. \(v=80\). On répète deux fois : \(v\leftarrow 0{,}75v\). Valeur finale ?
    3. \(s=0\). Pour \(k=1;2;3;4\), on fait \(s\leftarrow s+k\). Valeur finale ?
    4. \(u=3\). On répète \(u\leftarrow 2u\) jusqu'à obtenir \(u\geq 20\). Combien d'itérations ?
    5. Après la question 4, quelle est la valeur finale de \(u\) ?
    6. Dans une boucle de seuil, que représente le compteur \(n\) ?
    Coup de pouce

    Conseils

    • Repérer ce qui est répété.
    • Mettre à jour le compteur après chaque tour.
    • Pour un seuil, s'arrêter dès que la condition est vérifiée.

    Vigilance

    • Ne pas faire un tour de trop.
    • Le test du seuil se fait sur la valeur courante.

    Corrigé de la série B

    1. \(5\rightarrow 9\rightarrow 13\rightarrow 17\), donc \(\boxed{17}\).
    2. \(80\rightarrow 60\rightarrow 45\), donc \(\boxed{45}\).
    3. \(s=1+2+3+4=\boxed{10}\).
    4. \(3\rightarrow 6\rightarrow 12\rightarrow 24\). Il faut \(\boxed{3}\) itérations.
    5. La valeur finale de \(u\) est \(\boxed{24}\).
    6. Le compteur indique le \(\boxed{\text{nombre de tours effectués}}\).
    Méthode. Un tableau de trace évite les erreurs : ligne initiale, puis une ligne par tour.
    Vigilance. Dans une boucle « tant que », la condition d'arrêt n'est pas toujours atteinte exactement.

    Série C — Lire et contrôler un algorithme

    ⏱ 8 min · Calculatrice interdite

    Consigne. Associer un petit algorithme à une suite ou à une somme.

    1. L'instruction \(u\leftarrow u+6\) modélise-t-elle une évolution additive ou multiplicative ?
    2. L'instruction \(u\leftarrow 1{,}08u\) modélise-t-elle une hausse de \(8\%\) ?
    3. Pour \(u_0=2\) et \(u_{n+1}=u_n+5\), quelle instruction met à jour \(u\) ?
    4. Pour \(u_0=100\) et \(u_{n+1}=0{,}9u_n\), quelle instruction met à jour \(u\) ?
    5. Un algorithme additionne \(u_0+u_1+\cdots+u_5\). Combien de termes sont ajoutés ?
    6. Que faut-il initialiser pour calculer une somme dans une boucle ?
    Coup de pouce

    Conseils

    • Addition répétée : modèle arithmétique.
    • Multiplication répétée : modèle géométrique.
    • Une somme a besoin d'un accumulateur.

    Vigilance

    • De \(0\) à \(5\), il y a six rangs.
    • Ne pas oublier la valeur initiale de l'accumulateur.

    Corrigé de la série C

    1. \(u\leftarrow u+6\) : évolution \(\boxed{\text{additive}}\).
    2. Oui, multiplier par \(1{,}08\) correspond à une \(\boxed{\text{hausse de $8\%$}}\).
    3. L'instruction est \(\boxed{u\leftarrow u+5}\).
    4. L'instruction est \(\boxed{u\leftarrow 0{,}9u}\).
    5. Les rangs \(0;1;2;3;4;5\) donnent \(\boxed{6}\) termes.
    6. Il faut initialiser une variable, par exemple \(\boxed{s\leftarrow 0}\).
    Méthode. Un algorithme est une traduction opérationnelle : initialiser, répéter, mettre à jour, renvoyer.
    Vigilance. Un accumulateur non initialisé rend le calcul impossible à contrôler.

    Série D — QCM : sortie d'algorithme

    ⏱ 6 min · Calculatrice interdite

    Consigne. Choisir la seule réponse correcte.

    1. \(x=10\), puis \(x=x-4\).
      1. \(4\)
      2. \(6\)
      3. \(14\)
    2. \(\texttt{range(3)}\).
      1. \(1;2;3\)
      2. \(0;1;2\)
      3. \(0;1;2;3\)
    3. \(u=2\), puis trois fois \(u\leftarrow 3u\).
      1. \(18\)
      2. \(54\)
      3. \(6\)
    4. Un seuil \(u\geq 50\) est atteint à \(n=4\). On renvoie
      1. \(4\)
      2. \(50\)
      3. \(u_4-50\)
    5. Dans \(\texttt{L=[8,9,10]}\), \(\texttt{L[2]}\) vaut
      1. \(9\)
      2. \(10\)
      3. \(2\)
    6. Pour calculer une somme, on utilise surtout
      1. un accumulateur
      2. une racine
      3. une tangente
    Coup de pouce

    Conseils

    • Traiter chaque proposition par élimination.
    • Les indices Python commencent à \(0\).
    • Une sortie d'algorithme doit être interprétée.

    Vigilance

    • Ne pas lire \(\texttt{x=x-4}\) comme une égalité impossible.
    • Une variable peut changer plusieurs fois.

    Corrigé de la série D

    1. Réponse B : \(10-4=6\).
    2. Réponse B : \(\texttt{range(3)}\) donne \(0;1;2\).
    3. Réponse B : \(2\rightarrow6\rightarrow18\rightarrow54\).
    4. Réponse A : Le compteur renvoie le premier rang trouvé.
    5. Réponse B : \(\texttt{L[2]}\) est le troisième élément.
    6. Réponse A : Une somme se construit avec un accumulateur.
    Méthode. Pour un QCM algorithmique, refaire une trace très courte suffit souvent.
    Vigilance. Une réponse numérique doit être reliée à la variable affichée ou renvoyée.
