    Automatismes N21 — Exponentielle II : modèles

    24 questions sans calculatrice, réparties en 4 séries courtes à faire en quelques minutes. Chercher d'abord seul, puis ouvrir le corrigé.

    ⚡ Faire le QCM interactif 📄 Diaporama PDF à projeter 📖 Revoir la notion

    Série A —

    Consigne. Reconnaître le modèle et calculer un terme ou une valeur.

    1. Suite géométrique : \(u_0=8\), \(u_{n+1}=1{,}2u_n\). Calculer \(u_2\).
    2. Modèle continu : \(f(t)=8e^{0{,}2t}\). Calculer \(f(0)\).
    3. Dans \(N(t)=50e^{-0{,}1t}\), le signe de \(-0{,}1\) indique quoi ?
    4. Dans \(u_n=12\times 0{,}85^n\), le modèle est-il croissant ou décroissant ?
    5. Calculer \(e^0\).
    6. Simplifier \(e^{0{,}3t}e^{0{,}7t}\).
    Coup de pouce

    Conseils

    • Comparer le facteur \(q\) à \(1\).
    • Dans \(e^{kt}\), le signe de \(k\) donne le sens.
    • Au rang ou temps \(0\), on lit la valeur initiale.

    Vigilance

    • Ne pas confondre \(q^n\) et \(e^{kn}\).
    • Un coefficient négatif dans l'exposant donne une décroissance.

    Corrigé de la série A

    1. \(u_1=9{,}6\), puis \(u_2=11{,}52\). \(\boxed{u_2=11{,}52}\).
    2. \(f(0)=8e^0=\boxed{8}\).
    3. \(-0{,}1<0\) : le modèle est \(\boxed{décroissant}\).
    4. \(0{,}85<1\), donc \(\boxed{décroissant}\).
    5. \(\boxed{e^0=1}\).
    6. \(e^{0{,}3t}e^{0{,}7t}=\)\(e^t=\)\(\boxed{e^t}\).
    Méthode. Discret : suite géométrique \(u_n=u_0q^n\). Continu : exponentielle \(f(t)=Ce^{kt}\).
    Vigilance. Comparer les paramètres, pas seulement les valeurs numériques.

    Série B —

    Consigne. Passer d'une phrase à un coefficient multiplicateur ou à un modèle.

    1. Augmenter de \(12\%\) correspond à multiplier par ?
    2. Diminuer de \(7\%\) correspond à multiplier par ?
    3. Un capital \(C_0=500\) croît de \(4\%\) par période. Donner \(C_n\).
    4. Une quantité vaut \(120e^{0{,}03t}\). Donner la valeur initiale.
    5. Pour \(f(t)=300e^{-0{,}04t}\), calculer \(f'(t)\).
    6. Le modèle \(f(t)=Ae^{kt}\) est constant si quelle valeur de \(k\) ?
    Coup de pouce

    Conseils

    • \(p\%\) d'augmentation : \(1+\frac{p}{100}\).
    • Diminution : \(1-\frac{p}{100}\).
    • La dérivée de \(Ae^{kt}\) est \(Ak e^{kt}\).

    Vigilance

    • Un taux négatif n'est pas un coefficient multiplicateur négatif.
    • La valeur initiale se lit en \(t=0\).

    Corrigé de la série B

    1. \(1+0{,}12=\boxed{1{,}12}\).
    2. \(1-0{,}07=\boxed{0{,}93}\).
    3. \(\boxed{C_n=500\times1{,}04^n}\).
    4. \(120e^0=\boxed{120}\).
    5. \(f'(t)=\)\(300(-0{,}04)e^{-0{,}04t}=\)\(\boxed{-12e^{-0{,}04t}}\).
    6. \(\boxed{k=0}\), car \(e^{0t}=1\).
    Méthode. Identifier valeur initiale et facteur ou taux. Dériver \(e^{kt}\) : multiplier par \(k\).
    Vigilance. Le modèle discret utilise une puissance \(n\), le continu une exponentielle en \(t\).

    Série C —

    Consigne. Lire ou compléter mentalement des étapes d'algorithme de seuil.

    1. \(u_0=100\), \(u_{n+1}=0{,}8u_n\). Calculer \(u_1,u_2\).
    2. Avec \(u_0=100\), \(u_{n+1}=0{,}8u_n\), le seuil \(u_n<50\) est-il atteint pour \(n=2\) ?
    3. Dans une boucle while u < 1000, le test continue tant que ?
    4. Pour une croissance de \(15\%\), écrire la mise à jour de \(u\).
    5. Pour une décroissance de \(6\%\), écrire la mise à jour de \(u\).
    6. Si \(f(t)=40e^{0{,}05t}\), \(f\) est-elle croissante ?
    Coup de pouce

    Conseils

    • Mettre à jour \(u\), puis augmenter le compteur.
    • Lire strictement le symbole du seuil.
    • Croissance si \(k>0\).

    Vigilance

    • Ne pas inverser la condition d'arrêt.
    • Un seuil peut être dépassé entre deux rangs entiers.

    Corrigé de la série C

    1. \(u_1=80\), \(u_2=64\). \(\boxed{80;64}\).
    2. \(u_2=64>50\), donc \(\boxed{non}\).
    3. La boucle continue tant que \(\boxed{u<1000}\).
    4. \(\boxed{\texttt{u = 1.15*u}}\).
    5. \(\boxed{\texttt{u = 0.94*u}}\).
    6. \(0{,}05>0\), donc \(\boxed{oui}\).
    Méthode. Un algorithme de seuil répète : mise à jour, compteur, test. Pour \(Ae^{kt}\), le signe de \(k\) donne le sens.
    Vigilance. Ne pas confondre rang \(n\) et valeur \(u_n\).

    Série D —

    Consigne. Choisir la seule réponse correcte. Calculatrice interdite.

    1. Une baisse de \(20\%\) :
      1. \(1{,}2\)
      2. \(0{,}8\)
      3. \(-0{,}2\)
      4. \(20\)
    2. \(f(t)=7e^{-0{,}3t}\) est
      1. croissante
      2. décroissante
      3. constante
      4. négative
    3. Valeur initiale de \(N(t)=25e^{0{,}4t}\) :
      1. \(0{,}4\)
      2. \(e\)
      3. \(25\)
      4. \(25e\)
    4. \(u_n=6\times1{,}1^n\) :
      1. discret
      2. continu
      3. affine
      4. constant
    5. \((e^{2t})'=\)
      1. \(e^{2t}\)
      2. \(2e^{2t}\)
      3. \(te^{2t}\)
      4. \(2t\)
    6. Croissance continue :
      1. \(u_n=u_0q^n\)
      2. \(f(t)=Ce^{kt}\)
      3. \(f(x)=ax+b\)
      4. \(u_{n+1}=u_n+r\)
    Coup de pouce

    Conseils

    • Chercher le type de modèle.
    • Regarder le signe du paramètre.
    • Répondre sans justification longue.

    Vigilance

    • Une seule bonne réponse.
    • Le mot continu renvoie au temps réel \(t\).

    Corrigé de la série D

    1. Réponse B : coefficient \(0{,}8\).
    2. Réponse B : car \(-0{,}3<0\).
    3. Réponse C : car \(N(0)=25\).
    4. Réponse A : rang entier \(n\).
    5. Réponse B : dérivée de \(e^{2t}\).
    6. Réponse B : modèle exponentiel continu.
    Méthode. Identifier discret/continu avant de calculer. Le coefficient multiplicateur est toujours positif.
    Vigilance. Ne pas confondre taux et coefficient multiplicateur.
