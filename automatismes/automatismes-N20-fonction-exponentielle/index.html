    Automatismes N20 — Fonction exponentielle I

    24 questions sans calculatrice, réparties en 4 séries courtes à faire en quelques minutes. Chercher d'abord seul, puis ouvrir le corrigé.

    ⚡ Faire le QCM interactif 📄 Diaporama PDF à projeter 📖 Revoir la notion

    Série A —

    Consigne. Calculer rapidement. Réduire les expressions avec les propriétés de l'exponentielle.

    1. Simplifier : \(e^3\times e^5\).
    2. Simplifier : \(\dfrac{e^7}{e^2}\).
    3. Simplifier : \((e^2)^4\).
    4. Écrire sans quotient : \(\dfrac{1}{e^{-3}}\).
    5. Comparer à \(1\) : \(e^0\).
    6. Résoudre : \(e^x=1\).
    Coup de pouce

    Conseils

    • Additionner les exposants dans un produit.
    • Soustraire les exposants dans un quotient.
    • Utiliser \(e^0=1\).

    Vigilance

    • Ne pas écrire \(e^a+e^b=e^{a+b}\).
    • La fonction exponentielle est strictement positive.

    Corrigé de la série A

    1. \(e^3\times e^5=\)\(e^{3+5}=\)\(\boxed{e^8}\).
    2. \(\dfrac{e^7}{e^2}=\)\(e^{7-2}=\)\(\boxed{e^5}\).
    3. \((e^2)^4=\)\(e^{2\times 4}=\)\(\boxed{e^8}\).
    4. \(\dfrac{1}{e^{-3}}=\)\(e^3=\)\(\boxed{e^3}\).
    5. \(e^0=\boxed{1}\).
    6. \(e^x=1=e^0\), donc \(\boxed{x=0}\).
    Méthode. Produit : \(e^a e^b=e^{a+b}\). Quotient : \(\dfrac{e^a}{e^b}=e^{a-b}\). Égalité : \(e^u=e^v\Longleftrightarrow\)\( u=v\).
    Vigilance. Les propriétés portent sur les produits, pas sur les sommes.

    Série B —

    Consigne. Donner la dérivée de chaque fonction sur \(\mathbb R\).

    1. \(f(x)=e^x+3x\).
    2. \(g(x)=5e^x-2\).
    3. \(h(x)=xe^x\).
    4. \(p(x)=(x^2+1)e^x\).
    5. \(q(x)=e^x(2x-3)\).
    6. \(r(x)=e^x-x^2\).
    Coup de pouce

    Conseils

    • Dérivée de \(e^x\) : elle-même.
    • Pour un produit, utiliser \((uv)'=u'v+uv'\).
    • Réduire seulement si c'est lisible.

    Vigilance

    • Ne pas oublier la dérivée de \(x\) dans un produit.
    • Une constante seule a une dérivée nulle.

    Corrigé de la série B

    1. \(f'(x)=\)\(e^x+3=\)\(\boxed{e^x+3}\).
    2. \(g'(x)=5e^x=\boxed{5e^x}\).
    3. \(h'(x)=\)\(1\cdot e^x+x e^x=\)\(\boxed{(x+1)e^x}\).
    4. \(p'(x)=\)\(2xe^x+(x^2+1)e^x=\)\(\boxed{(x^2+2x+1)e^x}\).
    5. \(q'(x)=\)\(e^x(2x-3)+2e^x=\)\(\boxed{(2x-1)e^x}\).
    6. \(r'(x)=\boxed{e^x-2x}\).
    Méthode. Identifier somme, produit ou constante. Factoriser par \(e^x\) quand cela simplifie le signe.
    Vigilance. \(e^x>0\), donc le signe de \(P(x)e^x\) est celui de \(P(x)\).

    Série C —

    Consigne. Utiliser le signe de \(e^x\) pour déduire un signe ou une variation.

    1. Signe de \(3e^x\) sur \(\mathbb R\).
    2. Signe de \(-2e^x\) sur \(\mathbb R\).
    3. Signe de \((x-4)e^x\).
    4. Variation de \(f(x)=e^x-5\).
    5. Si \(g'(x)=(2x-6)e^x\), donner le signe de \(g'(x)\).
    6. Si \(h'(x)=-(x+1)e^x\), \(h\) est croissante sur quel intervalle ?
    Coup de pouce

    Conseils

    • Commencer par \(e^x>0\).
    • Un facteur positif ne change pas le signe.
    • Traduire le signe de la dérivée en variation.

    Vigilance

    • Ne pas chercher les zéros de \(e^x\) : il n'en a pas.
    • Un signe négatif devant change le sens.

    Corrigé de la série C

    1. \(e^x>0\), donc \(3e^x\) est \(\boxed{strictement positif}\).
    2. \(-2e^x\) est \(\boxed{strictement négatif}\).
    3. Le signe est celui de \(x-4\) : négatif si \(x<4\), nul en \(4\), positif si \(x>4\).
    4. \(f'(x)=e^x>0\), donc \(f\) est \(\boxed{strictement croissante}\).
    5. Signe de \(2x-6\) : négatif si \(x<3\), nul en \(3\), positif si \(x>3\).
    6. \(h'(x)\geqslant0 \Longleftrightarrow\)\( -(x+1)\geqslant0 \Longleftrightarrow\)\( x\leqslant -1\). Donc \(\boxed{]-\infty;-1]}\).
    Méthode. Factoriser par \(e^x\), toujours positif. Lire le signe du facteur restant.
    Vigilance. Un extremum peut apparaître quand la dérivée change de signe.

    Série D —

    Consigne. Choisir la seule réponse correcte. Aucune justification demandée.

    1. \(e^2e^{-5}=\)
      1. \(e^{-10}\)
      2. \(e^{-3}\)
      3. \(e^7\)
      4. \(-e^3\)
    2. La dérivée de \(4e^x-x\) est
      1. \(4e^x\)
      2. \(4e^x-1\)
      3. \(e^x-1\)
      4. \(4e^{x-1}\)
    3. \(e^x>0\) sur \(\mathbb R\) :
      1. vrai
      2. faux
      3. seulement si \(x>0\)
      4. seulement si \(x\geqslant0\)
    4. Si \(f'(x)=(x-2)e^x\), \(f\) décroît sur
      1. \(]-\infty;2]\)
      2. \([2;+\infty[\)
      3. \(\mathbb R\)
      4. \(\varnothing\)
    5. \(\dfrac{e^6}{e^8}=\)
      1. \(e^2\)
      2. \(e^{-2}\)
      3. \(e^{48}\)
      4. \(\dfrac{6}{8}\)
    6. L'équation \(e^x=e^4\) a pour solution
      1. \(0\)
      2. \(1\)
      3. \(4\)
      4. \(e^4\)
    Coup de pouce

    Conseils

    • Repérer la propriété utile avant de calculer.
    • Éliminer les réponses impossibles.
    • Toujours penser à \(e^x>0\).

    Vigilance

    • Une seule réponse correcte.
    • Le signe de \(e^x\) ne dépend pas de \(x\).

    Corrigé de la série D

    1. Réponse B : car \(e^2e^{-5}=e^{-3}\).
    2. Réponse B : car \((4e^x-x)'=4e^x-1\).
    3. Réponse A : car \(e^x>0\) pour tout réel \(x\).
    4. Réponse A : car le signe est celui de \(x-2\).
    5. Réponse B : car \(\dfrac{e^6}{e^8}=e^{-2}\).
    6. Réponse C : car \(e^x=e^4\Longleftrightarrow\)\( x=4\).
    Méthode. Réponses rapides : propriété puis décision. Pour une dérivée factorisée par \(e^x\), regarder l'autre facteur.
    Vigilance. Ne jamais remplacer \(e^x\) par \(x\).
